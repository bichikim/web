# Pomo 마케팅 계획

## 1. 방향

Pomo의 마케팅은 기능 설명보다 **집중을 함께하는 캐릭터의 이야기**를 먼저 보여준다. MiniMax H3로 짧은 애니메이션을 제작하고, Pomo가 공부·코딩·독서를 함께하는 순간을 연속된 에피소드로 전달한다.

핵심 메시지:

> 혼자 집중하는 시간이 외롭지 않도록.
> Pomo — Focus for more.

## 2. 스토리 콘셉트

사용자가 책상에 앉지 못하거나 집중을 이어가지 못하는 현실적인 순간에서 이야기를 시작한다. Pomo는 문제를 대신 해결하지 않고, 곁에서 먼저 책을 펴고 키보드를 치며 사용자가 시작하도록 돕는다.

### 기본 서사

1. 해야 할 일이 있지만 시작하지 못하는 사용자
2. 조용히 책상에 앉아 기다리는 Pomo
3. 사용자가 지정한 시작 대사를 말하는 Pomo
4. 둘이 함께 공부하거나 작업하는 집중 시간
5. 종료 대사와 함께 오늘의 작은 성취 확인

캐릭터의 대사는 실제 앱에서 사용자가 설정할 수 있는 문장으로 구성한다. 마케팅 영상의 인상적인 장면이 제품 경험으로 그대로 이어지게 한다.

## 3. 애니메이션 시리즈

MiniMax H3로 세로형 숏폼을 우선 제작하고, 같은 이야기의 가로형 버전을 랜딩 페이지와 소개 영상에 활용한다.

| 시리즈             | 이야기                                             | 보여줄 기능                |
| ------------------ | -------------------------------------------------- | -------------------------- |
| 시작하기 어려운 날 | Pomo의 한마디로 25분을 시작한다                    | 시작 대사, 뽀모도로 타이머 |
| 늦은 밤의 코딩     | 조용히 함께 키보드를 치며 오류를 해결한다          | 코딩 행동, 로파이 음악     |
| 비 오는 날의 독서  | 창밖의 비와 함께 한 장씩 책을 읽는다               | 독서 행동, 환경 음악       |
| 시험 전날          | 불안한 사용자를 재촉하지 않고 짧은 세션으로 이끈다 | 사용자 지정 응원 대사      |
| 오늘은 여기까지    | 종료 대사와 함께 작업을 정리하고 쉰다              | 종료 대사, 휴식 전환       |

각 영상은 하나의 감정과 하나의 제품 기능에만 집중한다. 여러 기능을 한 편에 모두 설명하지 않는다.

## 4. 콘텐츠 형식

- 10~20초: 감정적인 한 장면과 Pomo의 한마디
- 30~45초: 문제, 집중 시작, 작은 성취가 있는 완결된 에피소드
- 60~90초: 캐릭터와 세계관을 확장하는 시즌형 이야기
- 반복 영상: 로파이 음악과 공부 행동을 보여주는 집중 배경 영상
- 제작 과정: 캐릭터, 방, 대사와 애니메이션이 만들어지는 과정

숏폼은 TikTok, YouTube Shorts, Instagram Reels에 맞춰 세로형으로 제작한다. 랜딩 페이지에서는 대표 에피소드와 실제 앱 화면을 이어 보여줘 애니메이션만 보고 이탈하지 않게 한다.

## 5. 제작 원칙

- Pomo의 외형, 방, 색상, 목소리와 말투를 모든 영상에서 일관되게 유지한다.
- 영상마다 캐릭터 기준 이미지, 장면 설명, 카메라, 행동, 감정, 조명을 기록한다.
- AI 생성 결과의 손, 책, 키보드와 화면 왜곡을 검수한다.
- 애니메이션 장면과 실제 앱 기능을 혼동시키지 않도록 실제 화면에는 UI임을 명확히 표시한다.
- 사용한 모델, 음원, 음성, 캐릭터 자산의 상업적 이용 조건을 게시 전에 확인한다.
- 자막을 기본 제공하고 대사 없이도 이야기 흐름을 이해할 수 있게 만든다.

## 6. 출시 전개

### 1단계 — 세계관 소개

- Pomo의 책상과 하루를 보여주는 티저 공개
- “Pomo가 어떤 말을 해주면 좋겠나요?”로 대사 아이디어 모집
- 반응이 좋은 상황과 말투를 초기 기본 대사에 반영

### 2단계 — 기능 연결

- 시작·종료 대사가 실제 앱에서 재생되는 장면 공개
- 코딩, 글쓰기, 독서 에피소드를 차례로 공개
- 대기 목록 또는 체험판으로 연결

### 3단계 — 사용자 이야기

- 사용자가 만든 대사와 집중 루틴을 동의받아 소개
- 인기 대사를 새로운 애니메이션 에피소드로 제작
- 계절, 시험 기간, 프로젝트 마감에 맞춘 시즌 콘텐츠 운영

## 7. 초기 성공 지표

- 영상 시청 완료율과 반복 시청률
- 댓글에 작성된 대사 아이디어 수
- 영상에서 랜딩 페이지로 이동한 비율
- 랜딩 페이지에서 체험 또는 대기 목록으로 전환한 비율
- 애니메이션을 보고 기대한 경험과 실제 제품 경험의 일치 여부

조회 수만으로 성공을 판단하지 않는다. **Pomo와 함께 집중해 보고 싶다**는 반응과 실제 제품 체험 전환을 우선한다.
