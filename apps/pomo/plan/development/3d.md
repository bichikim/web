# 3D 장면과 상호작용

[개발 기술 계획으로 돌아가기](../development.md)

## 제작과 런타임

Blender는 Needle Engine 애드온을 사용해 장면과 애니메이션을 glTF/GLB 자산으로 내보낸다. Needle Engine은 별도 앱을 만들지 않고 SolidStart 웹 프로젝트에 통합한다.

```text
Blender
   ↓ Needle Engine Exporter
glTF/GLB와 런타임 자산
   ↓
SolidStart + Needle Engine
   ├─ 앱인토스 SSG
   └─ 브라우저 SSR
```

## 성능과 품질

Needle Engine 장면의 기본 목표 프레임레이트는 30fps로 설정한다. 사용자는 설정에서 목표 프레임레이트를 변경할 수 있다.

3D 품질은 낮음, 중간과 높음 등급으로 나눈다. 앱은 Needle Engine의 기기 정보와 초기 렌더링 구간의 실제 FPS를 사용해 품질을 자동 선택하며, 사용자는 설정에서 직접 변경할 수 있다. 품질 등급에 따라 렌더링 해상도, 그림자, 후처리와 LOD를 조절한다.

낮은 품질에서도 캐릭터의 메시와 텍스처 품질은 최대한 유지한다. 성능이 부족하면 책상 환경의 해상도, 그림자와 후처리를 먼저 낮춘다.

책상과 고정 환경은 Blender에서 베이크한 조명을 사용한다. 움직이는 캐릭터에는 실시간 조명과 제한된 실시간 그림자를 적용한다.

낮은 품질에서는 캐릭터의 실시간 그림자를 끄고 가벼운 접촉 그림자로 대체한다.

자동 품질 선택은 앱을 시작할 때 한 번만 실행하며 실행 중에는 자동으로 변경하지 않는다. 사용자가 직접 선택한 품질 설정은 자동 선택보다 우선한다.

TTS 합성 중 발생한 일시적인 프레임 저하는 기기 성능 판정과 사용자 품질 설정에 반영하지 않는다.

## 자산과 로딩

기본 캐릭터와 책상 장면의 3D 자산은 앱인토스 번들에 포함한다. 추후 추가되는 선택형 장면은 원격 자산으로 제공한다. 기본 3D 자산과 기본 음원을 포함한 `.ait` 번들은 압축 해제 기준 100MB 이하로 유지한다.

기본 3D 자산은 캐릭터, 책상 환경과 뽀모도로 상호작용 오브젝트로 분리한다. 각 자산은 독립적으로 로드하고 교체할 수 있어야 한다.

앱을 열면 저장된 화면 모드와 관계없이 조작 가능한 정적 2D 책상 장면을 즉시 표시한다. 저장된 모드가 3D라면 2D 화면에 3D 로딩 상태를 표시하고, 최소 3D 장면이 준비되면 자동으로 전환한다. 3D 자산은 캐릭터와 캐릭터 렌더링에 필요한 자산을 최우선으로 불러와 가장 먼저 렌더링하고, 책상 환경과 뽀모도로 오브젝트를 그다음에 불러온다.

캐릭터는 낮은 LOD와 저해상도 텍스처로 먼저 표시하고, 점진적 로딩이 진행되면서 고품질 메시와 텍스처로 교체한다.

텍스처와 메시 압축은 Needle Engine의 기본 프로덕션 최적화 설정을 사용한다. 실제 기기 검증에서 문제가 확인된 자산만 개별 설정을 조정한다.

## 캐릭터와 애니메이션

캐릭터 GLB 하나에 리그와 글쓰기, 키보드 치기, 책 읽기 애니메이션 클립을 함께 포함한다.

눈 깜빡임과 가벼운 호흡은 활동 애니메이션과 분리된 레이어로 구성하고 글쓰기, 키보드 치기와 책 읽기 애니메이션 위에 겹쳐 재생한다.

머리카락과 옷자락 일부에는 가벼운 스프링 본을 적용한다. 전체 머리카락이나 천을 대상으로 하는 실시간 물리 시뮬레이션은 사용하지 않는다.

캐릭터 대사는 발음별 비짐(viseme)으로 립싱크한다. 캐릭터 GLB에는 립싱크에 필요한 입 모양 블렌드셰이프를 포함한다. 대사를 말하는 동안 캐릭터의 눈과 머리는 사용자 방향을 바라보고, 상체도 기존 활동 자세를 유지하는 범위에서 조금 따라 움직인다.

사용자 얼굴은 화면 중앙에 있다고 가정하고 고정된 시선 목표를 사용한다. 실제 카메라나 얼굴 추적은 사용하지 않는다.

립싱크 타이밍은 별도의 발음 정렬 모델을 추가하지 않고 대사 텍스트의 발음을 비짐으로 변환한 뒤 합성 음성 길이에 맞춰 근사한다.

## 활동 선택

집중 세션을 시작할 때 사용자가 코딩, 공부 또는 독서 활동을 선택한다. 캐릭터는 선택한 활동에 따라 키보드 치기, 글쓰기 또는 책 읽기 애니메이션을 재생한다.

집중 세션 도중에도 활동을 변경할 수 있다. 활동을 변경해도 타이머는 유지하며 기존 활동 애니메이션에서 새 애니메이션으로 자연스럽게 전환한다.

사용자는 책상 위 노트북, 노트와 책 3D 오브젝트를 직접 선택해 코딩, 공부와 독서 활동을 변경한다.

선택 가능한 책상 오브젝트는 포인터를 올리거나 터치하면 은은한 윤곽을 표시한다. 현재 활동에 해당하는 오브젝트는 강조 상태를 유지하며 2D 화면에도 같은 피드백을 적용한다.

오브젝트는 한 번의 터치나 클릭으로 활동을 즉시 변경하고 선택 강조를 유지한다.

타이머가 시작되지 않은 상태에서 오브젝트를 선택하면 활동과 캐릭터 애니메이션만 변경한다. 타이머는 사용자가 뽀모도로 조작 화면에서 별도로 시작한다.

마지막으로 선택한 활동을 기기에 영속 저장하고 앱을 다시 열면 해당 활동과 캐릭터 애니메이션을 복원한다.

뽀모도로 휴식 시간에도 선택한 활동의 애니메이션을 그대로 유지한다. 별도의 휴식 애니메이션은 최초 출시 범위에 포함하지 않는다.

## 카메라와 뽀모도로

화면 왼쪽 위의 Safe Area 안쪽에 작은 `3D/2D` 화면 전환 버튼, 설정 버튼과 `?` 사용법 버튼을 나란히 항상 표시한다. 모든 버튼은 3D와 2D 화면에서 같은 위치를 사용한다.

설정 화면은 세로·작은 화면에서 뷰포트의 약 90%를 차지하는 모달로 열고, 넓은 화면에서는 왼쪽 사이드 패널로 표시한다.

별도의 온보딩은 제공하지 않는다. 첫 실행에서는 사용법 진입점을 가리키며 `사용법이 궁금하다면 눌러서 확인하세요`라는 안내만 한 번 표시한다.

`?` 버튼을 누르면 사용법 안내 화면을 열며, 사용자는 다음 다섯 장을 차례로 넘겨볼 수 있다.

1. 활동 선택
2. 뽀모도로
3. 음악
4. 대사와 목소리
5. 설정과 TTS 모델 다운로드

마지막 장에서는 TTS 모델을 먼저 내려받아야 대사를 설정할 수 있다고 안내한다.

사용법 화면은 `이전`과 `다음` 버튼으로 이동하며 현재 장을 함께 표시한다. 좌우 스와이프 이동은 제공하지 않는다.

사용법은 세로·작은 화면에서 뷰포트의 약 90%를 차지하는 모달로 열고, 넓은 화면에서는 중앙 모달로 표시한다.

3D 카메라의 위치는 고정한다. 사용자는 좌우와 위아래 회전만 좁은 범위에서 조작할 수 있으며, 조작을 끝내면 카메라가 부드럽게 기본 구도로 돌아온다.

책상 위 뽀모도로를 선택하면 카메라는 이동하지 않고 뽀모도로 오브젝트가 화면 중앙의 조작 구도로 이동한다. 오브젝트가 이동하는 동안 카메라 회전도 같은 시간에 맞춰 천천히 기본 구도로 돌아오며, 뽀모도로 조작 화면을 닫을 때까지 카메라 회전을 잠근다.

뽀모도로 조작 화면은 바깥 영역 선택, 뒤로 가기 또는 닫기 버튼으로 닫을 수 있다.

타이머 진행 중에도 조작 화면을 닫을 수 있다. 뽀모도로가 책상 위 자리로 돌아간 뒤에도 타이머는 계속 진행하며 남은 시간을 3D로 표시한다.

남은 시간과 세션 상태는 3D 뽀모도로에 렌더링한다. 시작, 일시 정지와 재개 같은 조작 버튼은 3D 오브젝트 위치에 맞춘 HTML 인터페이스로 겹쳐 표시한다.

뽀모도로의 남은 시간 숫자는 SDF 기반 3D 텍스트로 렌더링한다. 집중, 휴식과 일시 정지 상태는 서로 다른 아이콘과 색상으로 표시하며 색상에만 의존하지 않는다.

남은 시간 숫자는 1초마다 갱신하고, 별도의 진행 링은 경과 비율에 맞춰 부드럽게 움직인다.

## 2D 화면 모드

2D 화면은 단순한 오류 대체 화면이 아니라 발열과 전력 소모를 줄이거나 2D 표현을 선호하는 사용자가 직접 선택할 수 있는 정식 화면 모드다. 앱 번들에 포함된 정적 2D 책상 장면을 사용하며 HTML 타이머 조작, 음악과 TTS를 그대로 제공한다.

사용자가 마지막으로 선택한 3D 또는 2D 화면 모드를 기기에 영속 저장하고, 다음 앱 실행에서도 같은 모드로 시작한다.

타이머나 대사가 진행 중이어도 언제든 3D와 2D 모드를 전환할 수 있다. 전환 중에는 타이머, 음악과 재생 중인 대사를 중단하거나 다시 시작하지 않고 현재 상태를 그대로 유지한다.

2D 모드에서는 Needle Engine 컨텍스트를 일시 정지하고 3D 렌더링, 애니메이션, 물리 업데이트와 입력 처리를 모두 중단한다. 3D 장면 리소스는 빠른 복귀를 위해 메모리에 유지한다.

앱이 저장된 2D 모드로 시작하면 2D 화면을 먼저 표시한 뒤 3D 장면을 백그라운드에서 미리 불러온다. 로딩이 끝난 3D 장면은 렌더링하지 않고 일시 정지 상태로 유지한다.

3D 로딩을 시작하면 2D 화면 중앙에 `3D 준비 중` 문구를 먼저 표시한다. 문구는 잠시 뒤 왼쪽 위 `3D/2D` 전환 버튼 쪽으로 사라지고, 로딩이 끝날 때까지 버튼의 스피너와 상태 표시로 이어진다. 이 과정에서도 2D 화면은 계속 조작할 수 있다.

3D 장면을 불러오는 동안 사용자가 3D 전환 버튼을 누르면 2D 화면을 유지하고, 3D 장면이 준비되면 자동으로 전환한다.

3D 자동 로드는 최초 시도와 자동 재시도 두 번을 합해 총 세 번까지만 실행한다. 세 번 모두 실패하면 `3D 모델 로드 실패` 토스트를 표시하고 해당 실행에서는 2D 화면으로 전환한다. 저장된 3D 선택은 변경하지 않으며 사용자가 직접 실행할 수 있는 `다시 시도`를 제공한다.

2D 화면에는 글쓰기, 키보드 치기와 책 읽기 활동별 정적 캐릭터 일러스트 세 장을 제공하며, 활동을 바꾸면 해당 일러스트로 교체한다. 대사 재생 중에도 현재 활동 그림을 유지하고 음성, 자막과 말하기 표시만 제공하며 립싱크와 시선 애니메이션은 생략한다. WebGL이나 Needle Engine을 사용할 수 없거나 3D 장면이 실행 중 실패하면 타이머와 오디오를 중단하지 않고 2D 화면으로 전환한다.

활동별 2D 일러스트는 한 장씩만 제작한다. 세로와 가로 화면에서는 캐릭터와 핵심 책상 요소가 안전 영역 안에 남도록 화면 비율에 맞춰 이미지를 잘라 표시한다.

2D 화면에서는 정적 책상 이미지의 노트북, 노트와 책 위치에 화면 비율을 따라가는 터치 영역을 배치해 활동을 변경한다.

책상 위 뽀모도로 그림을 선택하면 그림이 화면 중앙의 조작 구도로 이동한다. 조작 방식과 닫을 때 책상 위 자리로 돌아가는 흐름은 3D 모드와 동일하다.
