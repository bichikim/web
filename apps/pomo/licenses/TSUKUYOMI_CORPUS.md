# 츠쿠요미짱 코퍼스 AI 음성 이용 기록

> 검토일: 2026-08-11
>
> 대상: `つくよみちゃんコーパス Vol.1 声優統計コーパス（JVSコーパス準拠）`
>
> 음성·편집: 夢前黎(Rei Yumesaki)

이 문서는 코퍼스로 AI 음성 모델을 학습하고 생성 음원을 Pomo에서 사용하는 경우의 내부
실무 기록이다. 법률 자문이나 원문 약관을 대체하지 않으며 출시 직전에 최신 약관을 다시
확인한다.

## 공식 자료

- [배포 및 이용약관](https://tyc.rei-yumesaki.net/material/corpus/)
- [기본 코퍼스 ZIP](https://tyc.rei-yumesaki.net/files/voice/tyc-corpus1.zip)
- [같은 성우의 추가 음성](https://tyc.rei-yumesaki.net/material/corpus/yoseatsume/)
- [대본 라이선스 설명](https://tyc.rei-yumesaki.net/material/corpus/cc-by-sa/)
- [캐릭터 라이선스](https://tyc.rei-yumesaki.net/about/terms/)
- [권리자 문의](https://www.rei-yumesaki.net/mail/)

기본 코퍼스는 약 14세의 고음·위스퍼 계열 애니메이션 캐릭터풍 음성을 목표로 한 100문장
자료다. 공식 설명상 녹음은 96 kHz/24-bit, 편집·출력은 96 kHz/32-bit float다. 실제 사용
전 ZIP 동봉 문서와 파일 구성을 별도로 확인한다.

## Pomo 적용 범위

현재는 다음 흐름의 프로토타입과 품질 검증에 사용한다.

1. 코퍼스 WAV와 대본을 비공개 학습 데이터로 보관한다.
2. 자체 음성 합성 또는 음색 변환 모델을 학습한다.
3. 학습 모델이 생성한 음원을 Pomo 콘텐츠 또는 서비스에서 사용한다.
4. 원본 WAV·대본·ZIP은 외부에 재배포하지 않는다.

현재 Pomo의 Supertonic 모델은 별도 라이선스로 관리한다. 츠쿠요미짱 조건은 이 코퍼스로
직접 학습하거나 그 음색을 계승한 모델·출력에만 적용한다.

## 이용 판단표

| 사용 방식                                            | 판단        | 조건                                                    |
| ---------------------------------------------------- | ----------- | ------------------------------------------------------- |
| 비공개 연구·학습                                     | 가능        | 원본을 외부에 공개하지 않는다.                          |
| 생성 음원을 영상·콘텐츠·수익화 활동에 사용           | 가능        | 금지 용도와 소재 재배포 제한을 지킨다.                  |
| 음성 합성 모델·소프트웨어·API 공개 또는 판매         | 가능        | 제품 크레딧, 이용 제한, 파생 배포 조건을 반영한다.      |
| 출력 음원을 다른 캐릭터의 더빙에 사용                | 가능        | 출력물 이용이며, 다른 캐릭터 전용 모델 제작과 구분한다. |
| 츠쿠요미짱이 아닌 캐릭터의 전용 음성 모델로 출시     | 사전 문의   | 공개 전에 사용 형태를 설명하고 서면 허락을 확보한다.    |
| 원본 코퍼스 또는 생성 음원을 범용 소재로 재배포·판매 | 원칙적 금지 | 필요한 경우 권리자의 개별 허락을 받는다.                |

개인·법인, 영리·비영리, 연구·개발 여부만으로 이용이 제한되지는 않는다. 다만 허용되는
사업 형태와 출력물의 사용 방식은 아래 조건을 모두 충족해야 한다.

## 제품에 필요한 크레딧

음성 합성 모델·소프트웨어·API를 공개할 때는 공식 약관의 다음 일본어 문구를 제품 설명이나
라이선스 화면 등 눈에 띄는 위치에 표시한다. 유료 제품은 결제 전 화면에도 표시한다.

```text
本ソフトウェアの音声合成には、フリー素材キャラクター「つくよみちゃん」（© Rei Yumesaki）が無料公開している音声データを使用しています。

■つくよみちゃんコーパス（CV.夢前黎）
https://tyc.rei-yumesaki.net/material/corpus/
```

한국어 안내가 필요하면 다음 번역을 함께 제공한다. 번역만으로 공식 예문을 대체하지 않는다.

```text
본 소프트웨어의 음성 합성에는 프리 소재 캐릭터 「츠쿠요미짱」(© Rei Yumesaki)이 무료 공개한 음성 데이터를 사용했습니다.

■ 츠쿠요미짱 코퍼스 (CV. 夢前黎)
https://tyc.rei-yumesaki.net/material/corpus/
```

- 다른 화자의 음색과 병합했다면 그 사실도 설명한다.
- 캐릭터 디자인이나 일러스트를 함께 쓰면 해당 소재의 별도 라이선스와 크레딧을 적용한다.
- 합성 소프트웨어가 생성한 개별 출력 음원에는 코퍼스 크레딧을 의무화하지 않아도 된다.
  출력물 사용자에게 별도 크레딧을 요구할지는 Pomo 이용약관으로 정할 수 있다.

## 모델과 출력 음원의 이용 제한

공개 모델·서비스의 이용약관에서 다음 행위를 금지한다.

- 사람을 비판하거나 공격하는 행위
- 특정 정치적 입장·종교·사상에 대한 찬반을 촉구하는 행위
- 자극적인 표현을 적절한 연령·콘텐츠 구분 없이 공개하는 행위
- 생성 음성을 제3자가 다시 음성 소재로 이용할 수 있도록 배포·판매하는 행위

생성 음원을 감상용 작품으로 배포·판매하는 것은 가능하다. 위 제한을 제품 약관에서 보장하지
못하는 경우에는 출시 전에 권리자와 협의한다.

## 데이터와 파생 모델의 배포

- 원본 ZIP, WAV, 대본은 원칙적으로 재배포하지 않고 공식 배포 페이지를 안내한다.
- 생성 음원을 범용 보이스 소재나 데이터셋으로 배포·판매하지 않는다.
- 원본 또는 생성 음원의 별도 납품·재배포가 필요하면 사전에 개별 허락을 받는다.
- 모델, 소스 일부 또는 음향 모델의 개조·재배포를 허용할 때는 파생 배포자에게도 코퍼스
  유래 부분에 공식 코퍼스 약관을 적용하도록 의무화한다.

음소 균형 대본은 CC BY-SA 4.0으로 공개되어 있다. 공식 설명상 코퍼스 Vol.1의 제작·배포
자체에 ShareAlike를 그대로 승계할 필요는 없지만, 대본이나 원본 음성을 독립 소재로 다시
사용할 때는 [별도 설명](https://tyc.rei-yumesaki.net/material/corpus/cc-by-sa/)과
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ja)을 재검토한다.

## 출시 체크리스트

- [ ] 공식 ZIP과 동봉 이용안내를 보관했다.
- [ ] 다운로드 날짜, SHA-256, 보관 위치를 아래 기록했다.
- [ ] 원본 데이터는 외부 다운로드가 불가능한 저장소에 보관했다.
- [ ] 제품 설명과 유료 결제 전 화면에 공식 크레딧을 표시했다.
- [ ] 다른 화자와 병합했다면 이를 공개했다.
- [ ] 서비스 약관에 출력 금지 용도와 소재 재배포 제한을 반영했다.
- [ ] 파생 모델 재배포자에게 코퍼스 약관 승계 의무를 부과했다.
- [ ] 다른 캐릭터의 전용 모델이라면 서면 허락을 확보했다.
- [ ] 출시 직전에 공식 약관과 캐릭터 라이선스 개정일을 재확인했다.
