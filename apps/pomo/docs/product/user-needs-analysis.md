# Pomo 사용자 니즈 1차 분석

기준일: 2026-09-16

상태: 공개 자료 기반 분석 초안

이 문서는 Pomo 실제 사용자의 인터뷰 결과가 아니다. 현재 Pomo에서 확인한 기능과
경쟁 서비스의 공식 설명, 공개 사용자 의견, 관련 연구를 대조해 다음 사용자
검증에서 확인할 우선순위를 정한다. 공개 자료가 Pomo 사용자에게 그대로 적용된다고
가정하지 않는다.

## 핵심 결론

현재 근거가 가장 일관되게 가리키는 문제는 “집중 앱 자체가 집중을 시작하는 데
필요한 추가 일이 되면 안 된다”는 점이다. 동시에 사용자는 단순 타이머만이 아니라
분위기, 진행감, 다른 존재의 조용한 동반감 중 하나를 통해 세션을 지속할 이유를
찾는다.

Pomo에는 장면, 음악, 캐릭터 대사, 타이머가 이미 있다. 따라서 다음 기능을 더하는
것보다 먼저 다음 세 가지를 검증해야 한다.

1. 사용자가 설정을 거의 하지 않고 첫 세션을 시작하는가.
2. 캐릭터의 조용한 동반감이 실제 세션 완료와 재방문에 영향을 주는가.
3. 장면·음악·대사 묶음이 타이머와 구분되는 유료 가치가 되는가.

## 증거 수준

| 수준               | 의미                                                                                                 |
| ------------------ | ---------------------------------------------------------------------------------------------------- |
| `Pomo 직접 관찰`   | Pomo 소스 또는 로컬 실행에서 확인한 내용이다.                                                        |
| `공식 제품 근거`   | 다른 서비스가 어떤 문제와 가치를 제품의 중심으로 설명하는지 보여준다. 수요의 독립적인 증명은 아니다. |
| `공개 사용자 의견` | 공개 커뮤니티의 개별 의견이다. 반복 여부와 표본 대표성을 확인해야 한다.                              |
| `연구 근거`        | 관련 연구의 결과다. Pomo의 캐릭터 동반 효과를 직접 검증한 결과는 아니다.                             |
| `Pomo 가설`        | 위 근거를 Pomo에 적용한 추론이다. 실제 사용자 검증 전에는 결론이 아니다.                             |

## 1. 시작 마찰을 낮추려는 니즈

### 외부 근거

별도 서비스인 [Pomo Timer](https://pomotimer.com/ko/)는 계정·광고·설정 없이
몇 초 만에 시작하는 경험을 전면에 내세운다. 이는 해당 서비스의 포지셔닝이지
전체 시장의 사실은 아니지만, 첫 세션 시작의 단순함을 핵심 가치로 선택한 사례다.

공개 커뮤니티의 한 [집중 앱 이탈 논의](https://www.reddit.com/r/pomodoro/comments/1v6alxq/what_makes_you_stop_using_a_focus_or_Pomodoro_app/)에서도
작성자는 과도한 설정·기능·광고·소액결제가 기본 타이머를 방해할 수 있으며,
타이머는 별도 작업 입력 없이 바로 시작되어야 한다고 말했다. 단일 사용자의
의견이므로 방향 신호로만 취급한다.

### Pomo와의 대조

Pomo는 로컬 실행에서 첫 집중 화면까지 진입할 수 있지만, 둘러보기는 21단계이고
장면·음악·대화·피드·기억 보조·설정이 함께 존재한다. 기능이 많다는 사실은
가치가 될 수 있지만, 첫 세션 이전에 모두 이해해야 한다면 시작 마찰이 된다.

### Pomo 가설

첫 방문자는 기본 장면과 기본 음악으로 바로 타이머를 시작하고, 고급 설정은 세션
이후에 발견하는 흐름을 선호할 가능성이 있다.

### 확인 방법

- 처음 보는 사용자가 설명 없이 첫 세션을 시작하는지 관찰한다.
- 시작 전 클릭 수, 도움 요청, 둘러보기 진입 여부, 중단 지점을 기록한다.
- `기본 시작`과 `설정 후 시작` 두 흐름의 첫 세션 시작률을 비교한다.

## 2. 조용한 동반감과 가벼운 책임감

### 외부 근거

[Focusmate의 공식 소개](https://www.focusmate.com/about/)는 시간 선택, 파트너
매칭, 라이브 공동 작업을 핵심 흐름으로 설명한다. [도움말의 세션 규칙](https://support.focusmate.com/en/articles/4044432-what-happens-during-a-focusmate-session-do-s-don-ts)은
시작 전에 할 일을 짧게 선언하고, 세션 중에는 조용히 작업하며, 끝에 결과를
확인하는 구조를 설명한다. 즉, 동반감은 계속 대화하는 기능보다 시작·작업·종료의
경계를 만드는 장치로 설계되어 있다.

다만 [사회적 맥락에 관한 체계적 문헌고찰](https://pubmed.ncbi.nlm.nih.gov/35379082/)은
다른 사람의 존재가 수행을 돕는 경우와 방해하는 경우가 모두 있음을 보고한다.
따라서 “동반감은 누구에게나 효과가 있다”고 일반화할 수 없다.

### Pomo와의 대조

Pomo는 사람과 실시간으로 연결하지 않고도 장면 속 캐릭터, 시작·종료 대사,
이벤트 음성을 제공한다. 이는 사람에게 관찰되는 부담을 줄인 조용한 동반감의
후보지만, 캐릭터가 실제로 책임감이나 집중 지속을 만들어내는지는 확인되지 않았다.

### Pomo 가설

캐릭터는 세션 중 자주 말을 거는 대화형 도구보다, 시작할 때 함께 앉고 끝날 때
작은 결과를 확인하는 경계형 동반자로 사용할 때 집중을 덜 방해할 가능성이 있다.

### 확인 방법

- 캐릭터 대사 없음, 시작 대사만, 시작·종료 대사 모두의 세 조건을 비교한다.
- 세션 중 대사 재생이 반갑게 느껴지는지 또는 흐름을 끊는지 묻는다.
- 사람과 연결되는 동반감, 캐릭터 동반감, 혼자 하는 집중 중 선호 이유를 구분한다.

## 3. 장면과 소리로 집중 환경을 만드는 니즈

### 외부 근거

[Tide](https://tide.fm/en_US/landing)는 자연음과 집중 타이머를 한 경험으로
묶어 설명한다. [Forest](https://www.forestapp.cc/)도 타이머와 사운드스케이프,
진행 상태, 앱 차단을 조합한다. 두 서비스는 시각·청각 환경이 타이머 주변의
부가 기능이 아니라 집중 경험의 일부가 될 수 있음을 보여준다.

### Pomo와의 대조

Pomo는 시간대·활동·시선·스타일 장면과 음악 플레이어를 제공한다. 기능 존재만
보면 환경 조성 니즈와 잘 맞지만, 경쟁 서비스도 자연음·사운드·시각 테마를
제공하므로 “장면과 음악이 있다”만으로는 차별점이나 유료 이유가 되지 않는다.

### Pomo 가설

장면·음악 자체보다 “이 작업을 시작하는 의식”과 캐릭터의 시작·종료 경험을
묶었을 때 Pomo만의 반복 가치가 생길 가능성이 있다.

### 확인 방법

- 기본 장면·음악만 사용한 세션과 대사까지 설정한 세션의 재사용 의향을 비교한다.
- 사용자가 장면을 고르는 이유가 집중 효과인지, 감정적 만족인지, 수집인지 묻는다.
- 여러 테마 중 실제로 반복 선택되는 테마와 한 번만 본 테마를 구분한다.

## 4. 진행감과 연속성을 원하는 니즈

### 외부 근거

Forest는 타이머 외에도 나무 성장, 집중 기록, 분석, 그룹 집중, 기기 간 계정
동기화를 제공한다. 공식 페이지는 핵심 타이머를 무료로 두고, 고급 분석·추가
사운드·커스텀 설정 등을 Plus 범위에 둔다. 이는 “첫 집중 시작”과 “반복 사용을
돕는 확장 기능”을 분리하는 패키지 사례다.

### Pomo와의 대조

Pomo의 초기 기술 계획은 집중 로그·통계를 초기 범위에서 제외했고, 현재 코드에는
로컬 저장과 로그인 UI가 함께 있다. 기능 감사에서 계정·기기 간 동기화의 종단 간
흐름은 확인하지 않았다.

### Pomo 가설

기록·통계·동기화는 첫 세션의 핵심 가치는 아니지만, 사용자가 Pomo를 반복 사용한
뒤에는 재방문과 유료 전환을 돕는 보조 가치가 될 수 있다.

### 확인 방법

- 첫 세션 사용자에게 통계를 보여주기 전에 필요한지 묻지 않는다. 먼저 다음 날
  다시 시작할 때 무엇을 기억하고 싶은지 확인한다.
- 세션 완료 뒤 “오늘 몇 분 했는가”보다 “다음에 무엇을 이어 하고 싶은가”를 묻는다.
- 기록·동기화·테마 중 어떤 확장을 위해 결제할 이유가 생기는지 비교한다.

## 5. 무료 핵심과 유료 확장을 구분하려는 니즈

### 외부 근거

Forest는 핵심 집중 경험을 무료로 제공하고 고급 기능을 구독으로 확장한다고
공식적으로 설명한다. 별도 서비스인 Pomo Timer도 기본 타이머는 무료로 두고,
의도 설정·전체 기록·사용자 배경을 Pomo+ 확장 기능으로 제시한다. 이 사례들은
가격 결론이 아니라, 사용자가 첫 집중 시작을 결제 장벽 없이 판단하게 하는
패키징 방식의 후보를 보여준다.

### Pomo와의 대조

Pomo에는 음악 앨범의 상품·오퍼·주문·권한 기반과 미리 듣기 경로가 있지만,
실제 구매·복원 흐름은 이번 감사에서 확인하지 못했다. 또한 현재 무료 기본
앨범이 로컬 실행에서 관찰됐다.

### Pomo 가설

타이머와 첫 장면을 유료로 잠그기보다, 반복 사용자가 선택할 수 있는 음악·장면·
대사·음성 테마 팩을 미리 보기와 함께 판매하는 편이 제품의 첫 가치를 훼손할
가능성이 낮다. 이는 사용자 검증 전의 사업 가설이다.

### 확인 방법

- 무료 핵심 세션을 먼저 경험하게 한 뒤 테마 팩을 제시한다.
- 패키지 이름보다 구매 후 얻는 결과를 설명하고, 무엇이 아쉬운지 묻는다.
- 일회성 구매·구독·구매하지 않음의 이유를 가격과 가치로 나누어 기록한다.

## 6. 방해받지 않으면서 변화를 원하는 니즈

### 외부 근거

공개 사용자 의견에는 같은 시작·종료 소리가 장기간 반복되면 알람처럼 피로해질
수 있다는 지적이 있었다. 이는 한 사람의 경험이므로 일반적인 사실은 아니지만,
집중 앱의 알림과 음성은 도움과 방해를 동시에 만들 수 있다는 테스트 항목을
제공한다.

### Pomo와의 대조

Pomo는 음악, 이벤트 대사, 음성 생성, 피드 음성 준비를 함께 제공한다. 콘텐츠가
풍부해질수록 세션 중 재생 시점, 음량, 반복, 취소 동작이 핵심 경험이 된다.

### Pomo 가설

사용자는 다양한 콘텐츠보다 “언제 조용해야 하는지 직접 통제할 수 있음”을 먼저
신뢰할 가능성이 있다.

### 확인 방법

- 시작·종료 대사와 세션 중 대사의 선호를 분리한다.
- 음성·음악의 음량, 음소거, 다음 재생, 재생 안 함을 쉽게 찾는지 확인한다.
- 세션 중 콘텐츠가 집중을 도운 순간과 방해한 순간을 구체적으로 기록한다.

## 이번 단계에서 내리는 운영 결정

아래는 시장 결론이 아니라 다음 검증을 위한 작업 결정이다.

1. 새 기능을 추가하기 전에 현재 기능으로 첫 세션 시작 흐름을 검증한다.
2. 첫 화면에서 피드·기억 보조·대화 편집을 모두 설명하지 않는다.
3. 캐릭터는 자주 개입하는 챗봇보다 시작·종료 중심의 조용한 동반자로 먼저 시험한다.
4. 수익화 실험은 핵심 타이머 잠금보다 테마·음악·대사 확장 팩부터 비교한다.
5. 통계·동기화·실시간 사람 연결은 니즈가 반복해서 확인되기 전까지 구현 우선순위를
   올리지 않는다.

1. 학생·지식 노동자·창작 작업자 중 5~8명을 대상으로 최근 집중 실패 상황을 듣는다.
2. Pomo를 처음 보는 사람에게 장면 선택 없이 첫 세션을 시작하게 한다.
3. 같은 과업에서 시작·종료 대사 유무만 바꾸어 비교한다.
4. 세션을 마친 뒤 다시 쓸 이유와 결제하고 싶은 확장을 각각 묻는다.
5. 반복되는 말이 아니라 실제 행동·중단 지점·현재 지출을 결정 근거로 기록한다.
