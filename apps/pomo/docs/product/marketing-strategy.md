# Pomo 마케팅 전략

상태: 실행 전략 초안

기존 [`docs/plan/marketing.md`](../plan/marketing.md)는 Pomo의 캐릭터와 애니메이션
스토리텔링 방향을 관리한다. 이 문서는 그 창작 방향을 실제 유입, 첫 세션,
재방문, 수익화 검증으로 연결하는 운영 전략을 관리한다.

현재 단기 유입 목표와 실행 순서는 [단기 유입 계획](./short-term-growth-plan.md),
실제 수치는 [유입 측정 로그](./traffic-log.md)에서 관리한다.

방문자 범위는 전세계다. 현재 제품 locale은 `ko`와 `en`이므로 첫 유입 실험은
영어를 기본 변형으로, 한국어를 비교 변형으로 운영한다. 다른 언어를 지원한다고
표현하지 않고, 국가·언어별 방문 데이터가 쌓인 뒤 번역 우선순위를 정한다.

현재 확인된 소유 채널은 [Pomo YouTube 채널](https://www.youtube.com/@pomofi-io)이다.
단기 실험에서는 새 채널을 만들지 않고 이 채널을 주 유입 허브로 사용한다. 채널의
현재 영상 수·구독자·조회수·최근 업로드는 별도 확인 전까지 사실로 가정하지 않으며,
영상별 링크 식별자와 Production 방문자를 연결해 평가한다.

현재 문서에는 외부 시장 규모, 채널별 평균 성과, 전환율을 넣지 않았다. 그런
수치는 캠페인 실행 시점에 최신 공식 자료나 직접 측정값으로 갱신한다.

## 목표

마케팅의 첫 목표는 많은 방문을 만드는 것이 아니라 다음 흐름을 검증하는 것이다.

```text
Pomo의 분위기와 문제 장면을 봄
        ↓
실제 앱에서 첫 집중 세션을 시작함
        ↓
타이머·장면·음악·대사 중 하나를 자기 루틴으로 설정함
        ↓
세션을 마치고 다시 사용함
        ↓
반복 가치가 확인된 콘텐츠를 구매함
```

광고 수익을 목표로 하지 않으므로 방문 수만 늘리는 콘텐츠보다 첫 세션과
재방문으로 이어지는 콘텐츠를 우선한다.

## 포지셔닝 가설

### 한 문장

Pomo는 혼자 시작하기 어려운 공부·작업 시간을 장면, 음악, 캐릭터의 대사와
함께 시작하게 하는 집중 공간이다.

### 메시지 계층

1. **문제:** 시작해야 하지만 혼자 집중을 시작하기 어렵다.
2. **결과:** Pomo와 함께 첫 집중 세션을 시작한다.
3. **차별 요소:** 타이머만이 아니라 장면, 음악, 직접 만든 대사, 기억 보조가 한 공간에 있다.
4. **확장 가치:** 사용자의 루틴에 맞는 분위기와 콘텐츠를 계속 추가할 수 있다.

“AI가 생산성을 높여준다”처럼 검증하기 어려운 넓은 표현은 주 메시지로 쓰지
않는다. 실제 화면에서 사용자가 볼 수 있는 행동과 결과를 보여준다.

## 대상 메시지 후보

| 상황             | 핵심 장면                               | 연결 기능             | 검증할 질문                                |
| ---------------- | --------------------------------------- | --------------------- | ------------------------------------------ |
| 시작을 미루는 날 | Pomo가 먼저 책상에 앉고 타이머를 시작함 | 시작 대사·뽀모도로    | 영상 뒤 실제 시작까지 이어지는가?          |
| 늦은 밤 코딩     | 캐릭터의 키보드 행동과 조용한 음악      | 활동 장면·음악        | 배경 감성이 아니라 작업 도구로 이해하는가? |
| 비 오는 날 독서  | 장면과 독서 행동이 이어짐               | 장면·음악             | 사용자가 자기 독서 루틴을 떠올리는가?      |
| 시험 전 복습     | 짧은 세션과 반복 대사                   | 타이머·기억 보조      | 공부 불안을 자극하지 않고 시작을 돕는가?   |
| 오늘의 마무리    | 종료 대사와 기록                        | 종료 이벤트·메모·일기 | 다음 날 재방문 이유가 생기는가?            |

이 표의 상황은 기존 창작 계획과 기능 구조에서 도출한 콘텐츠 후보다. 어느
상황이 실제 핵심 고객인지 아직 검증하지 않았다.

## 콘텐츠 운영

### 1. 짧은 상황 콘텐츠

10~20초 분량으로 한 감정과 한 기능만 보여준다. 예를 들어 “시작하기 어려운
날의 첫 25분”에서는 시작 대사와 타이머만 보여주고, 피드·캘린더·앨범을
한꺼번에 설명하지 않는다.

### 2. 실제 화면 연결 콘텐츠

캐릭터 영상 뒤에 실제 앱 화면을 연결한다. 장면이 생성 영상인지 제품 기능인지
혼동하지 않도록 실제 UI를 명확히 구분한다. 영상에서 본 대사가 실제 설정 화면에서
어떻게 재생되는지 보여주면 콘텐츠와 제품 사이의 기대 차이를 줄일 수 있다.

### 3. 사용자의 루틴 콘텐츠

사용자가 만든 대사, 장면, 집중 루틴을 동의받아 소개하는 후보군이다. 공개 전에는
대사·음성·이미지·음악의 사용 권한을 각각 확인한다. 사용자의 결과물을 바로
마케팅 자산으로 사용한다고 가정하지 않는다.

### 4. 테마 컬렉션 콘텐츠

수익화 후보인 음악·장면·대사 묶음은 판매 페이지보다 먼저 “어떤 집중 상황을
완성하는 컬렉션인지”를 보여준다. 무료 기본 경험과 유료 확장 경험의 차이를
콘텐츠 안에서 명확히 설명한다.

## 유입부터 결제까지의 실험

| 단계   | 실험                                   | 확인할 행동                       | 다음 판단                             |
| ------ | -------------------------------------- | --------------------------------- | ------------------------------------- |
| 관심   | 상황별 숏폼 2~3개를 같은 형식으로 공개 | 저장·프로필 이동·앱 진입          | 어떤 문제 장면이 진입을 만드는가      |
| 이해   | 실제 앱 화면과 기능 설명을 연결        | 첫 화면에서 기능 이해·시작        | 메시지가 제품 경험과 맞는가           |
| 활성화 | 첫 세션 시작을 가장 짧은 경로로 안내   | `focus_session_started` 후보 행동 | 온보딩 마찰은 어디인가                |
| 가치   | 장면·음악·대사 중 하나를 개인화하게 함 | 설정 변경·세션 완료               | 무엇이 첫 세션을 자기 것으로 만드는가 |
| 재방문 | 다음 세션을 위한 대사·장면·기록을 남김 | 다음 날 재진입·재시작             | 반복 가치가 있는가                    |
| 수익화 | 검증된 테마 팩을 설명·미리 보기로 제시 | 제안 조회·구매 의향·구매 완료     | 실제 결제 구현으로 넘어갈 수 있는가   |

이벤트 이름은 [사용자 니즈 조사](./user-needs-research.md)의 측정 초안과
맞춘다. 현재 제품에 모두 구현되어 있다는 뜻은 아니다.

## 채널 원칙

- 캐릭터와 분위기를 보여주는 채널에서는 감정과 상황을 먼저 보여준다.
- Pomo YouTube 채널에서는 영상마다 하나의 문제 상황과 하나의 CTA만 사용하고,
  설명란·고정 댓글의 링크 식별자를 분리한다.
- 검색·소개 페이지에서는 실제 기능, 지원 환경, 저장 방식, 가격 조건을 명확히 쓴다.
- 앱 화면을 보여주는 콘텐츠는 현재 배포 버전에서 실제로 가능한 동작만 사용한다.
- 콘텐츠마다 하나의 행동만 요청한다. 예: 첫 세션 시작, 대사 만들기, 테마 보기.
- 생성형 자산은 제품 내 실제 결과와 동일하다고 암시하지 않으며, 사용한 자산의
  상업적 이용 조건을 확인한다.

## 측정할 지표

초기에는 아래 순서로 본다.

1. 콘텐츠에서 앱으로 이동한 비율
2. 첫 화면에서 집중 세션을 시작한 비율
3. 시작한 세션의 정상 완료 비율
4. 첫 세션 뒤 다시 방문한 비율
5. 장면·음악·대사 설정을 실제로 사용한 비율
6. 유료 제안 조회에서 구매 완료까지의 비율
7. 사용자당 콘텐츠·음성·저장 비용

조회수만 높고 세션 시작이 늘지 않는 콘텐츠는 브랜드 인지도에는 기여할 수
있지만, 현재 수익화 목표의 직접 증거로 사용하지 않는다.

## 다음 실행안

   콘텐츠 세 가지를 만든다.
2. 각 콘텐츠에서 연결하는 기능을 하나로 제한한다.
3. 실제 앱에서 첫 세션까지 이동하는 경로를 관찰한다.
4. 반복 사용 이유가 확인된 상황만 유료 패키지 후보와 연결한다.
5. 결과와 다음 결정을 [결정 기록](./decision-log.md)에 남긴다.
