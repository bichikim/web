# Pomo 유입 측정 로그

이 문서는 [단기 유입 계획](./short-term-growth-plan.md)의 실행 결과를 날짜별로
기록한다. 숫자만 적지 말고 Production·기간·유입 경로와 함께 기록한다.

## 기록 기준

- 방문자 집계 시간대: UTC
- 운영자가 로그를 작성한 시각: Asia/Seoul 표기 가능
- 환경: Production 웹만 포함
- 고유 방문자: 사용 중인 Analytics 대시보드의 `Visitors` 기준
- 제외: 본인 방문, Preview, 봇, 자동화 요청
- 기준 기간: 하루 00:00~23:59
- 해석: 7일 이동 평균과 목표 하한 도달 일수를 함께 본다.

Vercel Analytics는 페이지뷰와 방문자 데이터를 대시보드에서 확인할 수 있다.
현재 Pomo 소스는 [`Analytics.tsx`](../../src/components/vercel/Analytics.tsx)에서
웹 pageview를 수집하도록 연결되어 있다. 세션 시작·완료는 현재 이 로그에 숫자를
임의로 채우지 않고, 별도 이벤트가 확인된 날부터 기록한다.

## YouTube 채널 기준

- 주 유입 채널: [Pomo YouTube 채널](https://www.youtube.com/@pomofi-io)
- 이 채널은 사용자가 제공한 유입 경로다. 이번 문서에서는 새 채널을 개설하는
  계획으로 해석하지 않는다.
- 현재 공개 영상 수, 구독자 수, 조회수, 최근 업로드 상태는 확인 전까지 기록하지
  않는다.
- D0에 YouTube Studio에서 접근 권한, 최근 업로드, 시청자 국가·언어, 영상별
  노출·시청·링크 유입 지표를 확인한다.
- YouTube 조회수는 Pomo Production의 고유 방문자와 같은 지표가 아니므로, 목표
  판정은 이 로그의 Production 방문자 수를 기준으로 한다.

## 목표 확인

- 목표 구간: 하루 고유 방문자 10~20명
- 안정성 조건: 7일 중 5일 이상 10명 이상
- 현재 달성 일수: 확인 필요
- 7일 이동 평균: 확인 필요
- 다음 판단일: 실행 D7, 실행 D14

## 기록 방법

1. 매일 같은 시간에 Production 대시보드에서 숫자를 확인한다.
2. 방문자와 pageview를 혼동하지 않는다.
3. 게시물·초대·커뮤니티별 링크 식별자를 기록한다.
4. 숫자가 급증하면 봇·본인 방문·Preview 유입 여부를 먼저 확인한다.
5. 결과를 [결정 기록](./decision-log.md)에 옮길 때는 관찰과 해석을 분리한다.
