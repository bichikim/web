# 타로 기능 계획

상태: 정·역방향과 카드별 설명 사전 조합 적용 · 2026-10-01

## 목표와 배치

사용자가 질문을 적고 1장 또는 3장을 뽑으면, Pomo의 대화용 Gemma 4가 해당 카드에 맞춰 성찰을 돕는 해석을 작성한다. 3장 뽑기의 위치는 왼쪽부터 `과거 · 현재 · 미래`로 고정한다.

**확정 배치:** 집중 화면의 기존 `기억 보조` 버튼과 패널 이름을 `생각 보조`로 바꾸고, 그 안에 `타로` 탭을 추가한다. 집중 화면의 버튼 수는 유지한다. 기존 학습·메모·일기·캘린더 탭도 같은 위치에 둔다. 타로 탭에서는 질문·카드·해석을 한 화면에 진행한다. 탭이 하나 더 생기는 것은 허용하되, 작은 화면의 탭 탐색과 본문 스크롤은 구현 후 확인한다.

관련 코드: [집중 화면 도구 모음](../../src/components/p-studio/Toolbar.tsx#L102), [도구 탭 목록](../../src/components/tools/Content.tsx#L7), [기억 도우미 탭](../../src/components/memory-assist/TabList.tsx#L4), [기억 도우미 본문](../../src/components/memory-assist/Content.tsx#L17).

### 배치 판단

| 후보         | 장점                                                  | 걸리는 점                                            |
| ------------ | ----------------------------------------------------- | ---------------------------------------------------- |
| 독립 버튼    | 찾기 쉽다                                             | 이미 많은 집중 화면 버튼이 더 늘어난다               |
| 도구 탭      | 버튼이 늘지 않는다                                    | 변환·계산 도구 사이에서 타로의 성격이 어색하다       |
| 생각 보조 탭 | 버튼이 늘지 않고 일기·메모와 성찰 경험을 묶을 수 있다 | 작은 화면에서 여섯 탭의 탐색을 확인해야 한다         |
| 대화 입력창  | Gemma 4와 가깝다                                      | 카드 뽑기와 결과를 대화 입력 흐름에 억지로 섞게 된다 |

`생각 보조`라는 이름은 기존 학습·기록 기능과 타로를 함께 설명한다. 구현 시 버튼의 보이는 이름, 툴팁, 대화상자 제목, 탭 목록의 접근성 이름, 데스크톱 창 제목과 둘러보기 문구를 함께 갱신한다. 코드의 내부 식별자는 외부 이름 변경과 별도로 판단한다.

## 첫 버전의 경험

1. 생각 보조의 타로 탭은 기본적으로 `3장`을 선택한 상태로 열고, 사용자가 `1장`으로 바꿀 수 있게 한다. 질문 입력은 선택 사항이며, 빈 질문에는 일반적인 성찰 요청을 사용한다.
2. `카드 뽑기`를 누르면 앱이 선택한 장수만큼 중복 없이 뽑는다. 카드에는 이름과 짧은 기본 의미를 글자로 표시한다. 3장에서는 각 카드 위에 `과거`, `현재`, `미래`를 표시한다. 공통 카드 양식의 아트 영역에는 기존 포모 장면 그림을 재사용하며, 카드별 신규 일러스트와 뒤집기 애니메이션은 만들지 않는다.
3. 뽑힌 카드의 위치·방향과 해당 방향의 사전 설명, 질문을 Gemma 4에 전달한다. 카드 이름·번호 또는 등급·계열·슈트의 상징과 의미는 카드별 설명에 미리 조합한다. 모델은 카드·위치·방향을 선택하거나 바꾸지 않고 질문에 연결해 해석한다.
4. 생성 중 상태와 취소 동작을 제공한다. 완료되면 카드 아래에 해석을 보여준다. 실패하면 같은 카드 구성과 질문으로 다시 시도할 수 있다.
5. 다시 뽑으면 이전 생성이 끝나거나 취소된 뒤 현재 선택한 장수로 새 카드를 뽑는다. 첫 버전에서는 결과 기록과 공유를 범위에 넣지 않는다.

뽑은 뒤 장수를 바꾸면 기존 카드와 해석을 지우고 새 방식을 선택한 상태로 돌아간다. 생성 중에는 장수 변경을 막고, 취소 후 변경할 수 있게 한다. 패널을 닫으면 진행 중인 생성은 취소하고, 완료된 결과는 같은 페이지에서 다시 열었을 때 유지한다. 새로고침하면 결과를 지운다.

첫 버전의 덱은 **메이저 아르카나 22장과 마이너 아르카나 56장, 총 78장**이다. 카드를 뽑을 때 정·역방향을 같은 확률로 정한다. 카드별 고정 정보는 한국어·영어 각각의 정방향·역방향 설명에 미리 조합하고, 선택된 방향의 설명만 모델 입력에 사용한다. 재시도와 질문 수정, 완료 후 모달 재진입에서는 뽑힌 카드와 방향을 유지한다. 역방향을 일괄적으로 부정하거나 정방향을 단순히 뒤집지 않고 카드마다 지연·과도함·내면화·회복 등의 흐름을 구분한다.

## 해석과 모델 계약

- 타로는 기기의 대화용 Gemma 4(`gemma-4-e2b`)로 해석한다. 기존 일회성 대화의 모델 준비, 다운로드 동의, 진행 상태, 실패와 취소 동작을 참고하되 서버 Luna 실행 설정이나 음성 재생은 타로 해석에 연결하지 않는다.
- 모든 환경에서 타로 탭을 표시하고 카드 뽑기는 사용할 수 있게 한다. 기기에서 Gemma 4를 실행할 수 없다면 카드 이름과 기본 의미를 보여주되 AI 해석이 제공되지 않는 이유를 설명한다. 지원 여부는 실제 실행 환경에서 판정하며 서버 모델로 자동 전환하지 않는다.
- 입력에는 카드 순서·위치·방향별 사전 설명·질문과 현재 앱 언어의 응답 형식을 명시한다. 1장은 해당 카드의 상징과 적용할 관점을, 3장은 과거·현재·미래 각각의 의미와 세 장을 함께 읽은 요약을 생성한다. 두 방식 모두 사용자가 스스로 생각해 볼 질문으로 마무리한다.
- 해석은 확정적인 미래 예측이나 의료·법률·투자 결정을 지시하는 문장으로 제시하지 않는다. 모델 출력은 사용자 화면에서 일반 텍스트로 표시한다.
- 사용자가 질문을 작성해도 카드 선택 결과와 모델 응답을 뒤섞지 않는다. 생성이 실패해도 뽑은 카드·위치·질문은 유지한다.
- 질문과 해석은 첫 버전에서 계정이나 브라우저 저장소에 보관하지 않으며 진단 로그에도 질문 원문을 남기지 않는다. 모델 입력과 결과를 화면에만 유지한다.
- 사용자 화면 문구, 카드 이름·기본 의미, 모델 응답 언어는 앱의 한국어·영어 설정을 따른다. 언어를 바꾸면 이전 언어의 해석을 지우고, 뽑힌 카드는 유지해 새 언어로 다시 해석할 수 있게 한다.

## 구현 순서와 완료 조건

### 1. 카드와 문구

- 78장의 카드 ID, 계열, 한국어·영어 이름, 키워드, 기본 의미를 별도 데이터로 정의하고 문구의 출처·이용 권리를 확인한다.
- 78장이 누락이나 중복 없이 정의됐는지 확인한다. 1장 뽑기는 카드 한 장을, 3장 뽑기는 서로 다른 카드 세 장을 과거·현재·미래 순서로 반환하는지 확인한다. 같은 결과를 재시도할 때 카드와 위치가 바뀌지 않아야 한다.

완료 조건: 모델 없이도 두 방식의 카드 선택과 글자 카드 표시가 동작한다.

### 2. 모델 연결

- 질문과 카드 정보를 해석 요청으로 만들고, 기존 Gemma 4 준비·다운로드 흐름을 연결한다. 한국어·영어 각각에서 카드 위치와 응답 언어가 맞는지 확인한다.
- 생성 중 닫기·취소·재시도 시 늦게 도착한 이전 응답이 현재 카드에 표시되지 않도록 한다.
- 대표적인 1장·3장 질문으로 응답 길이와 완료 시간을 확인하고, 3장 해석이 중간에 끊기지 않도록 생성 한도를 정한다.

완료 조건: 준비된 모델로 1장과 3장의 해석이 각각 생성되고, 미준비·미지원·취소·실패 상태를 사용자에게 구분해 보여준다. 미지원 환경에서도 탭과 안내가 표시된다.

### 3. 진입과 화면 검증

- 기존 기억 보조의 사용자 표시 이름을 생각 보조로 바꾸고 타로 탭을 연결한다. 집중 화면 버튼 수를 유지하며 작은 화면에서 탭 목록·본문 스크롤을 확인한다.
- 키보드로 열기, 장수 선택, 질문 입력, 뽑기, 취소, 닫기가 가능하고 카드의 위치와 결과가 보조 기술에 전달되는지 확인한다. 작은 화면에서 세 카드가 읽기 좋은 순서로 배치되는지도 확인한다.
- 관련 테스트를 실행하고 oxlint 오류를 해결한 뒤 `pnpm format`을 실행한다.

완료 조건: 집중 장면을 떠나지 않고 한 번의 타로 흐름을 완료할 수 있다.

## 확정된 범위

- 덱: 78장 전체 · 정방향/역방향 각 50%
- 기본 뽑기: 3장, 사용자가 1장으로 전환 가능
- 노출: 모든 환경에서 타로 탭 표시, 기기 Gemma 4 미지원 시 이유 안내

## 구현 검증 기록

- 카드 78장의 구성, 1장·3장 뽑기, 한국어·영어 프롬프트, 모델 동의·취소·재시도·언어 변경 상태를 테스트했다.
- 타로 화면의 글자 카드와 미지원 안내를 컴포넌트 테스트로 확인했다. 타입 검사, oxlint, oxfmt를 통과했다.
- 3400 로컬 화면에서 기존 3장 결과와 해석 표시를 확인했다. 공통 장면 아트를 넣은 카드 양식은 3장 가로 배치, 1장 중앙 배치, 모바일 세로 배치와 본문 스크롤을 확인했다.
- 렌더링 E2E는 개발 서버의 Vite SSR 환경 오류로 장면 캔버스가 나타나기 전에 실패했다. 브라우저 확인은 별도로 진행했다.
