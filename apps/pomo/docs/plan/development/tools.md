# 도구 개발 계획

상태: 1차 구현 및 로컬 검증 완료. 앱인토스 실기기 검증은 출시 전 별도로 진행한다.

## 목표와 진입점

집중 중 필요한 계산·변환을 Pomo 안에서 해결한다. 보조 메뉴 순서는 `도구 → 기억 보조 → 설정`으로 한다. `도구`는 새 버튼이라는 의미이며, NEW 배지와 표시 기간은 이번 범위에 포함하지 않는다.

도구 버튼을 누르면 도구 선택과 작업 영역이 있는 모달을 연다. 기존 [기억 보조](../../../src/components/PMemoryAssist.tsx), [설정](../../../src/components/PSettings.tsx), [모달](../../../src/components/PModal.tsx)의 버튼·표면·포커스 처리와 일관되게 설계한다. 640px 미만 화면에서는 선택 메뉴로 도구를 전환하고, 넓은 화면에서는 목록과 상세 화면을 함께 표시한다.

대상은 일반 웹과 앱인토스다. 각 단계에서 앱인토스 공식 문서를 확인하고 파일 선택·결과 저장 등 플랫폼 차이를 검증한다. 도구를 열거나 닫아도 진행 중인 집중 타이머와 음악을 유지한다.

## 분류와 언어

| 분류      | 도구                   | 노출      | 단계 |
| --------- | ---------------------- | --------- | ---- |
| 계산·변환 | 단위 변환              | 모든 언어 | 1차  |
| 글쓰기    | 글자 수 세기           | 모든 언어 | 1차  |
| 날짜      | 전역일 계산            | 한국어    | 1차  |
| 날짜      | 음력·양력 변환         | 한국어    | 1차  |
| 날짜      | 손 없는 날             | 한국어    | 1차  |
| 이미지    | 사진 배경 제거         | 모든 언어 | 2차  |
| 글쓰기    | 한국어 맞춤법·띄어쓰기 | 한국어    | 2차  |
| 문서      | PDF 변환               | 모든 언어 | 3차  |

- 평↔㎡는 단위 변환의 면적 항목에 넣고, 한국어일 때 평을 추가한다. 별도의 부동산 메뉴는 만들지 않는다. 세금·DSR·중개보수 계산은 이번 요청 범위에 포함하지 않는다.
- 음력·양력은 측정 단위가 아니라 날짜 체계를 바꾸는 기능이므로 날짜로 분리한다. 손 없는 날은 같은 날짜 변환 로직을 재사용한다.
- 한국어 전용 노출은 국가·IP가 아니라 앱에서 선택한 언어를 따른다. 기준은 [현재 언어 설정](../../../src/components/settings/general/General.tsx)이다.
- 한국어에서 다른 언어로 바꿔 선택 도구가 사라지면 공통 도구 목록으로 돌아간다. 남은 빈 분류는 표시하지 않는다.

## 1차 — 기본 도구와 한국어 날짜 도구

### 단위 변환

- 길이, 무게, 면적, 부피, 온도로 시작한다. 미터↔피트, kg↔파운드, ㎡↔평 등을 제공한다.
- 값 입력, 원본·대상 단위 선택, 단위 맞바꾸기, 결과 복사, 초기화를 제공한다.
- 계산 정밀도와 화면 반올림을 분리한다. 빈 입력, 음수, 소수, 큰 수, 잘못된 입력을 구분한다.
- 변환 상수와 온도 변환식은 구현 시 공식 기준으로 확인하고 출처와 검증 사례를 남긴다.

### 글자 수 세기

- 공백 포함·제외 글자 수와 UTF-8 바이트 수를 실시간 표시한다.
- 사용자가 보는 문자 단위로 글자 수를 정의하고 한글 조합, 이모지, 줄바꿈의 취급을 명시한다. UTF-8 바이트를 특정 채용·학교 시스템의 바이트 기준으로 안내하지 않는다.
- 입력 삭제와 결과 복사를 제공한다. 입력 원문은 기본적으로 서버 전송·영구 저장하지 않는다.

### 전역일 계산

- 입대일과 복무 구분으로 예상 전역일, 남은 날짜, 복무 진행률을 표시한다.
- 병무청 등 공식 자료로 지원 복무 구분과 적용 시점, 계산 규칙을 확인한 뒤 구현한다. 고정 개월 수만 더하는 방식으로 규칙을 추정하지 않는다.
- 다른 복무기간은 전체 복무일수를 직접 입력한다. 입대일을 1일째로 포함해 예상 전역일을 계산하며 한국 날짜를 기준으로 한다. 입대일·복무 구분·직접 입력 모드·일수를 웹 또는 앱인토스 저장소에 보관하고 별도 저장 안내 문구는 표시하지 않는다.

### 음력·양력과 손 없는 날

- 양방향 날짜 변환, 음력 윤달 선택, 지원 연도 안내, 유효하지 않은 날짜 처리를 제공한다.
- 한국천문연구원 자료를 기준으로 정확성·지원 범위를 검증한다. 라이브러리나 데이터는 배포 조건 확인 후 선택한다.
- 손 없는 날은 월별 달력과 날짜 목록으로 제공한다. 적용하는 민속 관습의 기준을 출처로 확인하고 길흉을 보장하는 표현을 쓰지 않는다.
- 윤달·연말 경계 등 공통 날짜 계산을 재사용한다. 같은 날짜의 결과 불일치를 막는 작은 비용의 확장 대비다.

### 구현 순서와 완료 기준

1. 도구 버튼·모달·목록과 언어별 노출을 만든다.
2. 단위 변환과 글자 수 세기를 연결한다.
3. 검증된 날짜 변환 기반으로 음력·양력, 손 없는 날을 연결한다.
4. 공식 복무 규칙을 검증하고 전역일 계산을 연결한다.
5. 두 플랫폼에서 아래 검증을 완료한다.

완료 기준: 모든 1차 도구의 입력→결과→복사가 동작하고, 기준 자료의 검증 사례 및 경계값 테스트가 통과한다. 한국어·영어 전환, 모바일·데스크톱, 밝은·어두운 테마, 키보드 탐색·닫기·포커스 복귀를 실제 화면에서 확인한다. 도구 사용 전후 타이머와 음악의 연속성을 검증한다.

## 2차 — 이미지와 한국어 교정

- 사진 배경 제거: 이미지 선택 → 원본·결과 비교 → 투명 PNG 저장. 입력 크기 제한, 처리 상태, 실제 취소, 실패 후 재시도를 제공한다.
- 한국어 맞춤법·띄어쓰기: 원문 입력 → 수정 제안 → 개별 적용 또는 전체 적용 → 결과 복사. 원문을 보존하고 제안별 되돌리기를 제공한다.
- 각 기능 착수 시 로컬 처리와 외부 API를 품질, 배포 라이선스, 다운로드 크기, 지연, 처리당 비용으로 비교해 선택한다. 공개 웹 도구의 무단 호출을 전제로 삼지 않는다.
- 외부 전송이 필요한 경우 전송 대상과 보관 정책을 화면에서 안내한다. 원문·파일 내용을 분석 로그에 남기지 않는다.
- 완료 기준: 대표 이미지·한글 문장으로 결과 품질을 평가하고, 모바일 메모리·취소·재시도·결과 저장을 검증한다. 외부 서비스를 선택하면 운영비와 요청 제한도 확정한다.

## 3차 — PDF 변환

- 1차 제안 범위는 이미지→PDF와 PDF→이미지다. Word·Excel↔PDF, OCR, 병합·분할·압축의 포함 여부는 3차 착수 시 별도로 확정한다.
- 페이지 선택·순서, 결과 미리보기, 저장을 제공한다. 파일 크기·페이지 제한과 암호화·손상 파일 오류를 구분한다.
- 엔진은 한글 글꼴·레이아웃 보존, 라이선스, 브라우저 메모리, 서버 처리 비용을 실제 문서로 비교한 뒤 선택한다.
- 완료 기준: 확정한 변환 조합에서 페이지 수·순서·방향·한글 표시가 검증되고 두 플랫폼에서 결과를 저장할 수 있다.

## 공통 구현·검증 원칙

- 도구 목록에 식별자·분류·언어 조건·지연 로딩 경로만 둔다. 2~3차 도구 추가에 필요한 작은 확장점이며 범용 플러그인 시스템은 만들지 않는다.
- 계산 로직과 화면을 분리하고, 무거운 엔진은 해당 도구를 사용할 때 로드한다. 1차의 계산·집계는 클라이언트 처리를 우선하며 날짜 데이터 공급 방식은 검증 후 확정한다.
- 기존 [캘린더 타입](../../../src/features/calendar/types.ts)은 Google·Microsoft 일정 연동 계약이다. 날짜 변환을 일정 계정 연결에 의존시키지 않는다.
- 스타일은 UnoCSS와 기존 토큰으로 정의한다. 모달의 겹침·클리핑·접근성은 기존 프리미티브로 유지한다.
- 테스트는 실제 계산 결과, 언어 전환, 실패·취소, 플랫폼 경계를 검증한다. 실행하지 않은 테스트와 출처만 확인한 규칙을 동작 검증으로 보고하지 않는다.
- 각 구현 단계에서 Oxlint 오류를 해결하고 `pnpm format`을 실행한다. 실행한 검증과 남은 제약을 기록한 뒤 해당 단계를 완료 처리한다.

## 1차 구현 기록

- 진입점: [PTools](../../../src/components/PTools.tsx), [도구 목록](../../../src/components/tools/Content.tsx). 한국어에서 다섯 도구, 영어에서 두 공통 도구를 표시한다.
- 공용 입력: [PDatePicker](../../../src/components/PDatePicker.tsx)는 직접 그린 달력, [PTimePicker](../../../src/components/PTimePicker.tsx)는 24시간 시·분 선택이다. 네이티브 date/time input을 사용하지 않는다. 현재 공용 헤드리스 패키지와 설치된 Kobalte 0.13.11에 날짜·시간 전용 구현이 없어, 연도·월·시·분은 기존 Kobalte 기반 [PSelect](../../../src/components/PSelect.tsx)를 재사용했다.
- 날짜 선택기는 ISO 날짜, 선택 범위, 이전·다음 달, 연도·월 선택, 방향키·PageUp·PageDown·Home·End·Escape, 선택 후 포커스 복귀를 제공한다. 기본 범위는 1900~2100년이며 소비자는 유효한 ISO min/max를 오름차순으로 전달한다.
- 계산 계약: [날짜 연산](../../../src/features/civil-date/index.ts), [단위·글자·복무·음력 변환](../../../src/features/tools/index.ts). 입력과 결과는 기기에서 처리한다. 음력 지원 범위는 양력 1900-01-01~2050-12-31이며, 경계 날짜의 역변환을 위해 음력 연도 선택은 1899년부터 제공한다.
- 복사: 웹 Clipboard API와 앱인토스 Clipboard.setText를 분기한다. 앱인토스 설정에 clipboard/write 권한을 선언했고 거부·실패 시 수동 복사 안내를 표시한다.
- 시간 선택기의 기억 보조 추가 적용은 중첩 모달에서 포커스 충돌이 관찰되어 포함하지 않았다. 공용 컴포넌트는 독립적으로 제공하며 기존 기억 보조 입력 동작을 유지한다.

### PR 전 리뷰 (2026-09-09)

전체 변경 범위를 두 번 검토했다. 1차에서 아래 P2 세 건을 실패하는 회귀 테스트로 확인하고 수정했다. 2차 전체 검토에서 추가 P0/P1/P2는 발견하지 못했다.

- 날짜 선택기의 이전·다음 달 버튼에서 Escape가 달력을 닫지 않았다. 달력 영역의 키 처리로 옮겨 닫기와 입력 버튼 포커스 복귀를 검증했다. 실제 Chrome에서 연도 목록의 Escape는 목록만 닫고 달력을 유지하는 것도 확인했다.
- 한 도구의 렌더링 오류가 이후 선택한 도구까지 막았다. 도구 전환 시 오류 경계를 새로 만들어 다른 도구를 사용할 수 있도록 했다.
- 입대일이 없으면 정상 복무기간 300일도 잘못된 입력으로 표시했다. 기간 필드 자체의 정수·범위 조건으로 오류 표시를 분리했다.

재현 테스트는 수정 전에 각각 실패했고 수정 후 통과했다. 손 없는 날 날짜가 직접 선택·복사할 때 붙는다는 후보는 Chrome의 실제 선택 문자열이 줄바꿈으로 구분되어 재현되지 않았다.
