# 대화 제작과 이벤트 연결

[개발 기술 계획으로 돌아가기](../development.md)

## 책임 분리

- `/dialogue` 페이지는 대화 작성, 음성 생성, 구간 미리 듣기와 저장을 담당한다.
- Pomo 설정의 `이벤트` 탭은 이벤트 목록과 이벤트별 대화 연결을 담당한다.
- Pomo 설정의 `대화` 탭은 저장된 대화의 듣기, 편집과 삭제를 담당한다.
- Pomo 런타임은 연결된 이벤트를 실행하고 음성 시간에 맞는 말풍선 텍스트를 표시한다.
- 이벤트 목록, 연결 상태와 재생 실행기는 Pomo 페이지 범위의 컨텍스트가 한 번만 소유한다.
- 설정 모달은 컨텍스트의 상태를 읽고 연결을 변경할 뿐 이벤트를 직접 초기화하거나 실행하지 않는다.

앱인토스 정적 빌드에서도 기존 대화를 열 수 있도록 편집 대상은
`/dialogue?dialogueId=<id>` 쿼리로 전달한다. 쿼리가 없으면 새 대화를 만든다.

## 최초 범위

- 사용자는 여러 대화를 현재 기기에 저장할 수 있다.
- 대화는 원문, 목소리 정보, 통합 음성과 구간별 텍스트 타임라인을 가진다.
- 저장된 대화는 별도 이름 없이 대사 내용으로 목록에서 식별한다.
- 작성 중인 대사는 탭의 세션 저장소에 자동 보관하고, 저장을 완료하거나 탭을 닫을 때 제거한다.
- `음성 만들기`는 모델이 준비되지 않았으면 내부에서 준비를 마친 뒤 곧바로 음성을 생성한다.
- 지원 이벤트는 `입장`, `포모도르 집중 시작·종료`, `포모도르 휴식 시작·종료`다.
- 이벤트 하나에는 여러 대화를 연결하고 `순차 모두`, `랜덤 모두`, `랜덤 1개` 중 재생 모드를
  선택할 수 있다. 기존 연결은 `순차 모두`로 이전한다.
- UI는 이벤트를 기준으로 나열하고 각 이벤트의 `대화 연결` 메뉴에서 저장된 대화를 복수 선택한다.
- 이벤트 카드에는 연결된 대화 수와 재생 방식을 표시하며 재생 조작은 중복 제공하지 않는다.
- 대화의 듣기, 편집과 삭제는 `대화` 탭에서만 제공한다.
- 편집과 삭제는 이벤트 연결과 분리해 `대화` 탭의 저장된 대화 목록에서 제공한다.
- 시작 대화는 Pomo를 새로 열 때 한 번 실행한다.
- 브라우저가 자동 재생을 막으면 `입장 음성 재생` 버튼을 표시한다. 이 버튼을 눌렀을 때만 음성과
  말풍선을 함께 시작한다. 장면, 설정과 음악 등 다른 조작은 입장 이벤트를 시작하지 않는다.
- `입장 음성 재생` 안내는 실제 말풍선과 같은 하단 도크와 배치 상태를 사용한다. 플레이어가 접혀
  있으면 최소 플레이어 옆에, 펼쳐져 있으면 플레이어 위에 표시한다.

## 이벤트 연결 동작

- 대화 선택지는 Kobalte `DropdownMenu`의 플로팅 복수 선택 목록으로 표시한다.
- 같은 대화를 여러 이벤트에서 재사용할 수 있다.
- 한 상태 전환에서 종료와 다음 시작 이벤트가 함께 발생하면 이벤트 순서대로 연결된 대화를 재생한다.

## 저장 모델

구조화 저장소에는 대화 메타데이터와 이벤트 연결을 저장하고, 바이너리 저장소에는 통합 WAV를
저장한다. 저장소에서 읽은 값은 Zod로 검증한다.

각 음성 청크에는 다음 정보를 저장한다.

- 청크 순서
- 청크에 대응하는 텍스트
- 통합 음성 안의 시작 시간
- 실제 PCM 샘플 길이로 계산한 재생 시간

시작 시간은 앞선 청크의 길이와 모델의 청크 사이 무음 시간을 누적해 계산한다. 음성 생성에 걸린
시간은 재생 타이밍으로 사용하지 않는다.

대화 수정은 새 음성과 구조화 데이터를 모두 저장한 뒤 이전 음성을 제거한다. 대화 삭제 시 연결된
이벤트와 음성도 함께 제거한다.

## 말풍선 동작

- 음성이 실제로 시작될 때 첫 텍스트를 표시한다.
- 다음 청크가 시작되면 해당 청크 텍스트로 교체한다.
- 청크 사이 무음에는 직전 텍스트를 유지한다.
- 마지막 청크가 끝나거나 재생을 취소하면 말풍선을 닫는다.
- 말풍선의 `음성 중지`는 일시 정지가 아니라 현재 음성과 자막 재생을 완전히 종료한다.
- 2D 장면, 음악 플레이어와 설정 조작은 대화 재생 중에도 유지한다.
- 대화 재생 중 접힌 음악 플레이어는 재생과 펼치기 버튼만 남는 최소 너비가 되고, 말풍선은
  플레이어 바로 아래에 배치된다.
- 대화 중 음악 플레이어를 펼치면 정상 너비로 돌아오며 말풍선은 계속 플레이어 아래에 배치된다.
  다시 접으면 대화가 끝날 때까지 플레이어 너비만 최소 크기로 복귀한다.
- 대화가 없을 때 접힌 음악 플레이어는 기존 너비를 유지한다.
- 말풍선은 현재 플레이어 상태에서 화면 안에 차지할 수 있는 세로 공간까지만 커진다. 본문이 그
  공간을 넘으면 화자명은 고정하고 대사 본문만 말풍선 안에서 스크롤한다.

말풍선은 장면 다음, 음악과 설정 조작 앞의 DOM 순서에 둔다. 레이어링을 위해 `z-index`를 사용하지
않는다.

## 구현 단계

1. 대화, 음성 구간과 이벤트 연결 스키마 및 저장소 계약
2. Supertonic 청크 결과의 텍스트·재생 시간 메타데이터
3. 전용 대화 생성·편집 페이지
4. 설정 탭의 이벤트 목록과 이벤트별 대화 연결
5. 입장 이벤트 실행, 오디오 재생과 말풍선 타임라인
6. 저장소, 타임라인, 이벤트 실행과 주요 UI 테스트

## 제외 범위

- 기기 간 동기화와 계정 저장
- 음성 구간의 수동 타임라인 편집
