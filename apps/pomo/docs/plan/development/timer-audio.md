# 타이머와 음악

## 뽀모도로 타이머

기본 주기는 집중 25분과 휴식 5분이며, 집중 4회가 끝나면 15분의 긴 휴식을 제공한다. 집중 시간, 휴식 시간과 긴 휴식 시간은 사용자가 설정에서 변경할 수 있다.

시간 설정은 변경 즉시 자동 저장하되, 진행 중인 타이머에는 반영하지 않고 다음 세션부터 적용한다.

사용자는 다음 단계 시작 방식을 설정에서 선택한다.

- 집중과 휴식 모두 사용자 시작
- 집중 종료 후 휴식은 자동 시작하고, 휴식 종료 후 집중은 사용자 시작
- 집중과 휴식을 모두 자동 시작

진행 중인 타이머는 일시 정지하고 다시 시작할 수 있다. 일시 정지 시 남은 시간과 정지 상태를 기기에 영속 저장하며, 정지 중에는 시간이 흐르지 않는다.

## 음악

- 음악 플레이어는 화면 하단의 작은 HTML 인터페이스로 제공하며 3D와 2D 화면 모드에서 공유한다. 기본 상태에서는 재생 상태와 곡명만 표시한다. 사용자가 선택하면 플레이어 자체가 확장되어 볼륨, 이전·다음 곡, 재생 방식과 곡 목록을 표시한다. 넓은 화면에서는 가로 한 줄로 길어지고, 세로 화면에서는 조작 항목을 두 줄로 배치한다.
- 확장된 플레이어는 바깥 영역을 선택하거나 축소 버튼을 누르면 미니 플레이어로 줄어든다.
- 뽀모도로 중앙 조작 화면이 열리면 음악 플레이어 UI를 완전히 숨긴다. 재생 중인 음악은 중단하지 않는다.
- 뽀모도로를 선택하면 음악 플레이어 바깥을 선택한 것으로 처리해 먼저 미니 상태로 축소한다. 뽀모도로 조작 화면을 닫으면 미니 플레이어로 다시 표시한다.
- 최초 출시의 기본 음원은 앱 빌드에 포함한다.
- 기본 집중 음악은 앱에 포함된 재생목록을 무작위 순서로 반복 재생한다. 사용자는 재생 방식을 무작위, 순차 또는 한 곡 반복으로 변경할 수 있다.
- 음악 조작은 재생, 일시 정지, 볼륨, 이전 곡, 다음 곡과 전체 곡 목록 선택을 제공한다.
- 사용자가 목록에서 곡을 선택하면 해당 곡부터 재생하고, 이후 순서는 사용자가 설정한 재생 방식에 따른다.
- 음악 볼륨, 재생 방식, 마지막 곡과 재생 위치를 기기에 영속 저장한다. 앱을 다시 연 뒤 첫 사용자 조작에서 `AudioContext`를 활성화하고 마지막 위치부터 재생한다. 음악 정지와 백그라운드 진입 시 재생 위치를 저장한다.
- 음악은 타이머 상태와 독립적으로 재생하고 일시 정지할 수 있다. 집중 세션이 진행 중이지 않아도 음악 플레이어를 사용할 수 있다.
- 집중 음악은 집중과 휴식 단계가 전환되어도 끊지 않고 계속 재생한다.
- 음악과 대사는 Web Audio API의 `AudioContext`와 별도 `GainNode` 채널로 재생한다. 캐릭터 대사가 재생되는 동안 음악 채널의 볼륨을 낮추고, 대사가 끝나면 기존 볼륨으로 복원한다.
- 브라우저의 자동 재생 정책에 맞춰 첫 사용자 조작에서 `AudioContext`를 활성화한다.
- 추후 추가 음원은 Vercel Blob에 저장하고 스트리밍한다.

서버는 음악 목록과 공통 콘텐츠를 제공하며 Vercel에 배포한다. Supertonic 3 INT8 모델 파일은 Vercel Blob에 저장한다.

집중 기록과 통계는 최초 출시에서 제외하고 추후 기능으로 구현한다.
