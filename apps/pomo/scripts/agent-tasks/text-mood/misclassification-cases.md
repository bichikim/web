# 글 분위기 오분류·약한 감지 사례

실험 페이지에서 발견한 오분류, 판단 경계와 약한 보조 속성 감지를 기록한다. 원문과 사용자 판정을 보존하고, 사례가 충분히 모이면 학습 데이터 보강에 사용한다.

## 기록 원칙

- 입력 문장은 수정하지 않고 그대로 기록한다.
- 사용자가 의도한 분위기를 기대 결과로 삼는다.
- 실제 결과에는 주 분위기, 가까운 분위기, 점수 차이를 함께 남긴다.
- 한 사례만으로 재학습하지 않고 비슷한 사례를 모아 분포를 확인한다.

#### 관찰

- `무너질 듯`, `위태로웠지만` 같은 위협 표현이 어두움·공포 점수를 높인 것으로 보인다.
- 문장 전체의 `낡은 집`, 고요한 창가와 작은 꽃의 이미지는 쓸쓸함·그리움에 더 가깝다.
- 비슷한 구조인 `낡은 장소 + 남겨진 사물 + 희미한 생명` 사례를 추가로 수집할 필요가 있다.

- 표면적으로 긍정적인 `덕분에`, `완벽해졌다`가 평온·여유와 밝음·즐거움 점수를 높인 것으로 보인다.
- `부정적 사건의 나열 + 긍정적 평가` 구조를 냉소·비꼼 학습 데이터에 우선 보강할 필요가 있다.

4. 안개, 밤, 오래된 장소가 나오면 실제 감정보다 신비·몽환이나 공포에 과하게 끌린다.
5. 따뜻한 돌봄에 과거와 거리감이 섞이면 쓸쓸함·그리움이 애정을 덮는다.
6. 불안과 공포, 분노와 긴장의 각성도는 잡지만 감정의 방향을 세밀하게 나누지 못한다.

### 보강 우선순위

1. **P0 — 장난스러움:** 의인화, 과장, 엉뚱한 인과와 가벼운 상황극을 집중 보강한다.
2. **P0 — 냉소·비꼼:** 부정적 상황과 긍정적 평가가 충돌하는 대조 문장을 보강한다.
3. **P1 — 희망·기대:** 실패·파괴·어둠 뒤의 재시작을 불안·공포와 대조해 학습한다.
4. **P1 — 쓸쓸함·그리움:** 폐교, 옛 역과 남겨진 흔적을 신비·몽환과 대조한다.
5. **P1 — 각성도 대조:** 밝음과 분노, 불안과 공포를 동일한 문장 강도로 짝지어 보강한다.
