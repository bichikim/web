# Runtime storage

이 디렉터리는 앱에서 만든 설정과 상태를 영속적으로 저장하고 복원하는 공통 로직을 제공합니다. 앱이 종료된 뒤에도 저장한 값이 유지되며, 다음 실행에서 다시 불러와 이전 상태를 이어갈 수 있도록 합니다.

실제 저장 방식은 실행 환경에 따라 달라질 수 있습니다. 기능을 사용하는 쪽에서는 특정 저장 기술에 직접 의존하지 않고, 이 디렉터리가 제공하는 공통 읽기·쓰기 계약을 사용합니다. 새로운 실행 환경이나 저장 방식이 추가될 때도 같은 계약을 구현해 확장할 수 있습니다.

## 동작 원칙

- 저장할 값을 공통 형식으로 직렬화하고, 불러온 값은 각 기능이 제공한 파서로 검증합니다.
- 값이 없거나 손상되었거나 현재 형식에 맞지 않으면 유효한 앱 상태로 사용하지 않습니다.
- 실행 환경에 맞는 저장소를 연결하고, 여러 저장소를 사용하는 환경에서는 값을 동기화하고 복구합니다.
- 비동기 쓰기가 겹치면 이전 작업이 최신 값을 뒤늦게 덮어쓰지 않도록 쓰기 순서를 조정합니다.
- 저장소를 사용할 수 없거나 작업이 실패한 경우 호출부가 기본값 사용, 재시도, 오류 표시 같은 대응을 선택할 수 있도록 일관된 결과를 제공합니다.

저장 값의 형식이 바뀌는 경우에는 기존 값을 읽을 수 있도록 파서에서 변환하거나, 사용할 수 없는 값으로 판단해 기본 상태로 복원합니다.
