# createSingleFlight

같은 인스턴스와 키로 요청한 작업 중 실행 중인 Promise만 공유합니다. 메모 정리·삭제와 이전 음성 이관에서 사용합니다.

- 첫 작업을 호출 즉시 실행하고, `.finally()`로 키를 해제하는 Promise를 저장해 그대로 반환합니다.
- 그 Promise가 진행 중이면 이후 작업을 호출하지 않습니다. 첫 호출의 작업과 인자가 우선합니다.
- 성공과 실패 모두 키를 해제하므로 다음 호출은 새 작업을 실행합니다. 결과와 원래 거부 사유를 그대로 전달합니다.
- 키가 다르거나 인스턴스가 다르면 독립적으로 실행합니다. 메모 정리와 삭제는 같은 키를 쓰더라도 별도 인스턴스를 사용합니다.
- 작업이 Promise를 반환하기 전에 던지는 동기 예외는 즉시 전파하고 키를 등록하지 않습니다.
- 작업이 Promise를 반환하기 전의 동기 재진입은 공유하지 않습니다. 이 경우 각 실행이 완료될 때 키를 해제하는 기존 소비자의 동작을 유지합니다. 선등록이나 취소 기능을 제공하지 않습니다.

내장 `Map`과 `Promise.finally`를 사용합니다. 기존 `memoizeAsync`는 성공 결과를 보관하고, keyed queue는 중복 요청을 각각 실행하므로 이 계약을 대체하지 않습니다. 저장소 변경·재시도·오류 기록·결과 fallback 정책은 소비자가 소유합니다. 인스턴스 내부의 공유이며 여러 서버 인스턴스 사이의 잠금으로 사용할 수 없습니다.
