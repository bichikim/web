# 검증과 인계

- 최종 문서의 동일한 revision을 대상으로 중립·양 끝·중간·복합 포즈를 렌더링한다. 원본과 후보는 같은 카메라·배경·파라미터·물리 조건에서 비교한다.
- 단독 파츠, 인접 조합, 전경 숨김, 전체 모습을 검토한다. 작은 구멍뿐 아니라 부피·명암·가림·접합부·알파와 실루엣을 확인한다.
- 모션은 구간별 캡처와 실제 연속 재생을 함께 확인한다. 물리의 복귀·반전·반복과 편집 UI의 변경 반영도 검사한다. 정지 프레임 캡처가 연속 물리 동작 검증을 대신하지 않는다.
- 최종 파일을 저장하고 새 세션에서 다시 읽어 같은 모델·자산·포즈가 표시되는지 확인한다. 로드 실패로 이전 화면이 남은 상태를 성공으로 보고하지 않는다.
- 원본·편집 가능한 문서·레시피·report·실제 렌더와 입력·출력·엔진 해시를 함께 전달한다. 생성 출처·프롬프트·seed는 실제 사용한 범위에서 기록하고 인증 정보는 제외한다.
- 구조 검사, 실제 앱 적용, 검증한 동작 범위, 남은 결함, 사용자 수용 여부를 구별한다. 별도 런타임이 최종 대상이면 해당 환경의 로드·재생도 완료 기준에 포함한다.
