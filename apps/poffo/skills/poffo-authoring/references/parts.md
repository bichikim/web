# 파츠 준비

- 승인된 그림과 원본 해시·크기·색 공간·알파·배치를 기록한다. 화면 좌우와 캐릭터의 좌우, 원본 픽셀·crop·모델·부모·UV 좌표계를 구별한다.
- 독립 움직임, 부착점, 앞뒤 관계와 목표 변형으로 분리 경계를 정한다. 현재 전경 실루엣이나 명암선을 물체의 구조 경계로 오인하지 않는다.
- 가림 물체를 치웠을 때 드러날 영역과 조립용 겹침 여유를 완성한다. 서로 다른 면 사이로 파츠가 통과하면 앞뒤 분리·그리기 순서·클리핑 중 실제 엔진이 지원하는 구조를 선택한다.
- 정상인 원본 픽셀을 재사용하고 수정 범위를 제한한다. 생성한 숨은 면은 재질·선·무늬·광원을 연결하고 인위적인 절단선과 이중 윤곽을 제거한다. 가이드 마스크, 모델 생성, 출력 후처리의 기여를 구분한다.
- 파츠 단독·밝고 어두운 배경·원본 좌표의 전체 조합·전경 숨김을 확인한다. 실제 회전과 변형에서 구멍·잔존 물체·색차·알파 테두리가 없는지 검사한다. 이동 합성만으로 리깅 전체를 검증하지 않는다.
- 초해상화는 선택 사항이다. 구조와 경계를 먼저 고치고 RGB·알파·UV 대응을 유지하며, 최종 해상도의 자산으로 다시 검증한다.
