# 메시와 리깅

- 기존 문서의 scene·parameters·parameterBindings·physics·motions와 파츠 연결을 함께 읽는다. 그림 교체 시 정점 순서·UV·키폼의 의존성을 확인하고 이관할 수 없는 기존 리그를 일괄 재메시하지 않는다.
- 외곽·가닥 끝·오목한 경계·관절·주름에 맞춰 메시를 구성한다. 퇴화·뒤집힘·UV 불일치와 메시 밖의 유효 알파를 검사한다. 메시 확대를 숨은 면 제작으로 대체하지 않는다.
- 전체 방향·원근·국소 변형·물리의 책임을 계층으로 구분한다. 부착점과 자유도를 정하고 부모·자식에 같은 변형을 중복 적용하지 않는다.
- 파라미터 기본값·범위·중립·양 끝을 정한 뒤 중간 보간과 복합 입력을 검사한다. 가까운 면과 먼 면의 폭·노출, 접합부 추종과 본체 형태를 각각 확인한다.
- 물리는 길이·무게감·재질에 맞춰 진폭·응답·지연을 조정한다. 마스크·그림자·공유 드라이버·복제 형상도 같은 동작에서 검토한다.
- 실제 렌더의 부피·실루엣·가림 전환·뿌리 미끄러짐·가닥 소실을 확인한다. 빈틈이 없거나 스키마가 유효하다는 이유만으로 자연스러운 움직임을 보장하지 않는다.
