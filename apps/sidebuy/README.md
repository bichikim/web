# SideBuy

SideBuy는 온라인 쇼핑에서 사용자가 필요한 조건, 구매할 제품, 최적 구매처를 차례로 결정하도록 돕는 구매 의사결정 서비스다.

- 공식 도메인: <https://sidebuy.io>
- 현재 단계: 제품 및 인프라 기획
- 상세 계획: [PLAN.md](./PLAN.md)

## 제품 목표

상품을 많이 나열하기보다 사용자의 조건과 리뷰 근거를 바탕으로 후보를 1~2개까지 좁히고, 정확한 제품 옵션과 판매처를 비교해 최종 결정을 돕는다.

1. 필수 조건과 선호 조건을 정리한다.
2. 조건과 리뷰를 바탕으로 구매할 제품을 결정한다.
3. 동일한 제품과 옵션을 검증하고 최적 구매처를 결정한다.

## 핵심 원칙

- 필수 조건을 충족하지 못한 상품은 규칙으로 제외한다.
- 추천 순위와 설명은 검증 가능한 사양, 리뷰, 가격 데이터를 근거로 한다.
- 브랜드, 모델, 용량, 색상과 구성 수량까지 동일한 상품인지 확인한다.
- 가격과 재고에는 수집 시점을 표시한다.
- 광고와 제휴 수익은 추천 순위에서 분리하고 사용자에게 공개한다.
