# 기억을 되살리는 메모 앱

## 한 줄 소개

메모를 보관하는 데서 끝나지 않고, 잊을 만한 시점에 다시 보여 주어 사용자가 중요한 생각을 오래 기억하도록 돕는 도구형 앱이다.

## 해결하려는 문제

사람은 좋은 생각, 배운 내용, 지키고 싶은 다짐을 메모하지만 대부분 다시 열어 보지 않는다. 기존 메모 앱은 기록과 검색에는 강하지만, 기록한 내용을 적절한 시점에 떠올리게 하는 기능은 부족하다.

이 앱은 메모를 외부 저장소가 아니라 **기억을 반복해서 자극하는 재료**로 다룬다.

## 핵심 사용 흐름

1. 사용자가 기억하고 싶은 내용을 짧게 메모한다.
2. 앱이 메모의 중요도와 사용자의 반응을 바탕으로 다음 노출 시점을 정한다.
3. 잊을 만한 시점에 알림으로 메모를 다시 보여 준다.
4. 사용자는 `기억남`, `희미함`, `잊음`, `그만 보기` 중 하나로 반응한다.
5. 앱은 반응에 따라 다음 알림 간격을 늘리거나 줄인다.

기록 → 회상 → 반응 → 간격 조정의 순환으로 기억을 강화한다.

## 알림 알고리즘 초안

초기 버전은 단순한 간격 반복 방식으로 시작한다.

- 최초 노출: 작성 후 1일
- `기억남`: 기존 간격의 2배 후 노출
- `희미함`: 기존 간격과 비슷한 시점에 다시 노출
- `잊음`: 1일 이내에 다시 노출
- `그만 보기`: 반복 알림 종료 및 보관

다음 요소를 점진적으로 반영할 수 있다.

- 사용자가 설정한 중요도
- 알림을 확인하고 반응한 비율
- 자주 반응하는 요일과 시간대
- 메모를 연속해서 기억한 횟수
- 알림 피로를 막기 위한 일일 노출 상한

정교한 학습 모델보다 사용자가 예측하고 조절할 수 있는 규칙을 우선한다. 알림에는 다음 노출 시점과 그 이유를 표시한다.

## MVP

- 텍스트 메모 작성·수정·보관
- 메모별 중요도 설정
- 간격 반복 기반 알림 예약
- 알림에서 메모 내용 미리 보기
- 네 가지 회상 반응 기록
- 반응에 따른 다음 노출 시점 자동 조정
- 오늘 다시 볼 메모 목록
- 메모별 노출 및 반응 이력
- 알림 일시 정지와 일일 알림 수 제한

## 제품 원칙

- **회상이 중심이다.** 메모 관리 기능보다 다시 떠올리는 경험을 우선한다.
- **부담이 적어야 한다.** 한 번의 복습은 몇 초 안에 끝나야 한다.
- **사용자가 통제한다.** 알림 빈도, 시간대, 중요도, 반복 종료를 직접 조절할 수 있어야 한다.
- **알림을 남발하지 않는다.** 확인하지 않은 메모가 쌓이면 새 알림을 줄이고 묶어서 제시한다.
- **원문을 존중한다.** AI 요약이나 문제 생성은 선택 기능으로 두고, 사용자가 적은 문장을 기본 자극으로 사용한다.

## 성공 지표

- 알림을 받은 뒤 회상 반응을 남긴 비율
- 7일·30일 뒤에도 반복 중인 메모 비율
- 메모당 평균 유효 복습 횟수
- 사용자가 `기억남`을 연속으로 선택한 비율
- 알림 끄기 및 앱 삭제로 이어지는 알림 피로 지표

## 확장 아이디어

- 메모 내용을 가린 뒤 먼저 떠올리게 하는 회상 카드
- 메모에서 질문을 자동으로 만드는 선택형 AI 기능
- 사진, 음성, 링크 메모 지원
- 위치나 일정에 맞춘 맥락 알림
- 관련 메모를 묶어 하나의 기억 주제로 복습
- 충분히 기억한 메모를 자동으로 졸업시키는 기능

## 검증할 가설

> 사용자는 직접 저장한 메모를 잊을 만한 시점에 짧게 다시 접하면, 메모 앱을 단순 보관함이 아니라 지속적인 기억 보조 도구로 사용한다.

초기 검증에서는 알고리즘의 정교함보다 알림이 실제로 유용하게 느껴지는지, 반복 노출이 부담스럽지 않은지를 먼저 확인한다.
