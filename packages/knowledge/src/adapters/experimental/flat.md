# 질문별 평면 근거 확인 후보

기존 진단 (로컬 보관: `.local/evaluation/inspection/quality/project/hybrid.md`)의 입력 구조와 프롬프트를 제품 어댑터에 연결한 선택형 후보다. `classifyResearchPair`의 `evidenceReview: 'flat'`을 지정하면 질문마다 원문·해당 질문·그 질문의 인용문만 보낸다. 제안 답변이나 다른 질문은 넣지 않는다. 기존 답변 감사는 그대로 수행하며 두 검사 모두 승인해야 질문을 닫는다. 기본 CLI 방식은 변경하지 않는다.

모델이 반환한 정확 인용을 해당 질문의 근거 ID에 연결한다. 인용이 다른 질문에만 있거나 원래 두 주장에만 있고 해당 질문의 근거에는 없으면 거부한다. `undetermined`는 인용이 비어 있어야 하며 미해결 질문 원문을 보존한다. 이유·질문의 기존 길이 제한은 자르거나 완화하지 않는다. 정확 인용 존재와 파서 통과는 의미상 충분한 근거의 증명이 아니다.

감사 시작 전에 질문 N개와 답변 감사 1회를 합친 N+1회를 예약한다. 부족하면 [호출 예산 계약](research.md)에 따라 감사 전체를 시작하지 않고 미검토 답과 근거를 남긴다. 후보를 기본값으로 승격하려면 실제 전체 검색 경로의 의미·호출 비용·회귀 검증이 필요하다.
