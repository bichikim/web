# Cache API의 저장과 HTTP 캐시 헤더 {#policy}

MDN을 바탕으로 작성한 평가용 요약이다. 확인일: 2026-09-08.

Cache API는 스크립트가 Request와 Response 쌍을 저장하고 조회하는 인터페이스다. HTTP 캐싱 헤더를 자동으로 따르지 않는다. HTTP 캐시가 헤더를 따르는 동작과, 스크립트가 Cache API에 응답을 넣는 동작을 구분한다.

출처: https://developer.mozilla.org/en-US/docs/Web/API/Cache
