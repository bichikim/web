## 결정과 검증

후보 버전 5를 채택하지 않고 버전 3을 복원했다. 오프라인 요청 캡처에서 복원된 요청 본문과 캐시 키가 이전 버전 3 기록과 정확히 일치했다. 이는 새 모델 품질 평가가 아닌 복원 검증이다. [요약](summary.json)에 결과를 기록했다. 이후 다른 후보에는 버전 4·5를 재사용하지 않는다.

원문에 없는 생략 부호 연결은 거부하되 원문에 실제 있는 생략 부호는 허용하는 테스트를 추가했다. 복원 후 테스트 316개·타입·lint·포맷 검사를 통과했다. 프로덕션 인용 검증 로직은 그대로이며, 모델 출력의 생략 부호를 자동 제거하거나 정답을 바꾸지 않았다.

다음 설계 후보는 모델이 인용문을 다시 쓰게 하는 대신 원문 구간의 식별자를 선택하게 하고 원문에서 인용을 추출하는 방식이다. 아직 구현·검증하지 않았으며, 정확한 구간 선택과 응답 길이·호환성 검증이 필요하다. 추가 문구만 바꾸는 실험과 구분해 설계한다.
