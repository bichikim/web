# 에디터·스튜디오·뷰어 전환 최적화

상태: 공통 헤더·뷰포트 구현 및 전환 자원 유지 검증 완료. 전환 시간의 변경 전후 비교 측정은 후속 항목으로 남긴다.

- 모델 표시, 확대·이동, 화면 맞춤, 눈금, 배경과 보기 버튼을 공통 뷰포트로 묶는다.
- 정점·디포머 편집 표시와 입력 처리는 에디터에서만 연결한다. Studio·Viewer에는 편집 표시를 만들지 않는다.
- 전환 시 불필요한 문서 파싱, 텍스처 업로드와 플레이어 재생성을 줄이고, 모델·파라미터·선택 모션·재생 위치·카메라 상태의 유지 범위를 정리한다. 기존 JSON 호환은 유지한다.
- 같은 모델로 세 화면을 왕복하며 렌더링·확대·이동·보기 버튼과 에디터 전용 표시를 검증한다. 대형 모델의 전환 시간을 변경 전후로 측정하고, 화면 깜빡임·중복 캔버스·리소스 누수가 없는지 확인한다.

## 헤더 공통화

상속 대신 공통 베이스 헤더에 화면별 콘텐츠를 조합한다.

```text
베이스 헤더
├─ 에디터 헤더
└─ 런타임 헤더
   ├─ Studio
   └─ Viewer
```

- 베이스 헤더는 메뉴·제목·화면별 도구·작업 공간 이동의 공통 배치와 스타일을 담당한다.
- 에디터 헤더는 파일·편집 메뉴, 모델링/애니메이션 전환, 패널 표시와 브러시 도구를 제공한다.
- 런타임 헤더는 모델 불러오기, 모션 선택·재생, 배경색과 런타임 전용 도구를 제공한다.
- 공통 헤더의 인스턴스를 유지하려면 화면 전환 분기 바깥에 공통 호스트를 두어야 한다. 베이스 컴포넌트 추출만으로 화면 전환 시 재마운트가 사라지지는 않는다.
- 상태 의존성은 해당 도구에 한정하고, 재생 시간·파라미터 변경이 메뉴·탐색·에디터 도구의 재마운트를 일으키지 않도록 한다.

## 확인 기준

- 에디터↔Studio↔Viewer 왕복 시 공통 헤더·뷰포트의 DOM과 플레이어 생명주기가 의도대로 유지되는지 확인한다. 유지가 불가능한 경계는 이유와 초기화 범위를 명시한다.
- 화면별 메뉴와 도구, 선택 표시, 팝업 위치, 키보드 포커스, 뒤로·앞으로 이동을 보존한다.
- 같은 모델의 렌더링과 기존 파일 호환을 유지하면서, 대형 모델의 전환 시간과 문서 파싱·텍스처 업로드·플레이어 생성 횟수를 변경 전후로 비교한다.

## 구현 범위와 유지 경계

- `WorkspaceProvider`가 공통 헤더·카메라·캔버스의 소유권을 유지하고 화면별 아웃렛으로 같은 DOM을 이동한다. `BaseHeader`에는 에디터·런타임 도구를 조합한다.
- 에디터는 계속 유지하고 런타임 컨트롤러는 첫 진입에 생성한 뒤 재사용한다. Studio 그래프의 지연 로딩은 뷰포트와 분리한다.
- 동일 세션 전환에는 문서를 다시 읽거나 파싱하지 않는다. 저장된 문서와 동일한 객체이면 전환용 저장도 반복하지 않는다. 변경된 문서는 저장 후 이동한다.
- 에디터 선택·히스토리·편집 파라미터와 런타임 수동 입력·모션·재생 여부·재생 시점은 각각 유지한다. 카메라는 세 화면에서 공유한다.
- 런타임에서 모델을 불러오면 에디터에도 한 번의 문서 교체로 반영한다. 다른 세션을 선택하거나 렌더러가 새 문서를 수용하지 못하면 이전 자원을 해제한다.
- 정점·디포머 DOM은 에디터에서만 표시한다. 비활성 화면의 파일 메뉴와 단축키를 차단하고 얼굴 추적 카메라는 해제한다.
- 단독 `PuppetEditor` 사용은 공통 표면을 로컬로 생성하며 기존 사용 방식을 유지한다.

## 검증 기록

- 통합 테스트에서 에디터→Viewer→Studio→에디터→Viewer 왕복 시 헤더·뷰포트·캔버스의 객체 동일성을 확인했다. 문서 읽기 1회, 플레이어 생성 1회, 전환 중 해제 0회를 확인했다.
- 외부 세션 이동 시 문서 읽기와 플레이어 교체가 발생하고 이전 플레이어를 해제하는 별도 경계를 검증했다.
- 초기화 중 들어온 문서 변경은 마지막 문서로 모아 적용하며, 적용할 수 없는 경우에만 렌더러를 다시 생성한다. 초기화 실패·언마운트 후 완료 시 자원 해제를 검증했다.
- 실제 브라우저에서 122개 파츠·20,297개 정점 모델로 세 화면을 왕복했다. 동일한 보기 설정 ID와 카메라, 정지한 재생 시점 4.64초의 유지, 런타임의 정점 표시 부재를 확인했다.
- 전환 전후의 밀리초 단위 성능 수치는 측정하지 않았다. 이번 검증은 DOM·플레이어 생성 횟수와 실제 화면 동작에 한정한다. GPU 텍스처 업로드 횟수는 별도로 계측하지 않았다. 그래프 등 화면별 도구 전체를 항상 같은 DOM으로 유지하는 것은 범위에 포함하지 않는다.

- 관련 단위 테스트 69개와 통합 테스트 45개가 통과했다. 공간 편집 오버레이 분리 후 캔버스 단위 테스트 15개도 다시 통과했다.
- 실제 브라우저의 뒤로·앞으로 이동과 메뉴 Escape 포커스 복원을 확인했고, 브라우저 콘솔 오류는 없었다.
- 패키지 타입 검사, player/editor/editor-element/converter 전체 빌드, 변경 파일 oxlint와 oxfmt 검증을 통과했다.
