# Laya 실험실

질문을 실행하고, 정답 예제를 추가해 브라우저 안에서 Laya scorer를 학습하는 데모다. 모델 추론과 학습은 Web Worker에서 실행한다. `choice`, `score`, `noul`을 지원하며 학습 전후 확률과 단계별 손실을 표시한다.

## 실행

저장소 루트에서 실행한다. 모델 준비 방법은 [패키지 README](../README.md#모델-준비)에 있다. 다국어 모델 폴더를 `LAYA_MULTILINGUAL_MODEL_DIR`에 지정하면 서버가 기본 모델 위치 `/models/laya-multilingual/`로 제공한다. 비교용 영문 모델은 `LAYA_MODEL_DIR`로 지정하면 `/models/laya/`에서 제공한다.

```sh
LAYA_MULTILINGUAL_MODEL_DIR=/tmp/laya-multilingual-browser \
LAYA_MODEL_DIR=/tmp/laya-browser pnpm exec vite \
  --config packages/laya-wasm/demo/vite.config.ts
```

[http://127.0.0.1:3400/](http://127.0.0.1:3400/)에서 **모델 선택**의 다국어·영문 토글로 모델을 고른 뒤 모델 불러오기 → 분류 지시문·분류할 문장 입력 → 추론하기 → 정답 선택 및 예제 추가 → 학습하고 결과 비교 순서로 사용할 수 있다. 모델이 연결되어 있으면 선택을 잠그며, 연결 해제 후 다른 모델을 고를 수 있다. UI에서 경로를 입력하지 않으며 패키지의 `LayaWasm.load({baseUrl})` API는 그대로다.

각 예제에는 추가 당시의 질문·선택지·입력이 저장된다. 예제를 여러 개 추가한 뒤 반복 횟수와 학습률을 정할 수 있다. 학습 중지는 현재 WASM 연산이 끝난 뒤 다음 단계 전에 적용되며, 완료된 단계의 가중치는 남는다.

같은 입력의 고정 인코더 표현은 한 학습 실행 안에서 최대 32 MiB까지 재사용한다. 반복 횟수를 늘려도 각 단계의 점수 계산층은 계속 갱신한다. 재학습·취소 후 재실행에서는 캐시를 새로 만든다.

## JSONL로 예제 가져오기

정답 예제의 **JSONL 가져오기**로 파일을 선택하면 기존 목록 뒤에 모든 예제가 추가된다. 이어서 **학습하고 결과 비교**를 누르면 목록 전체를 학습한다. 한 줄이 잘못되어도 파일 전체를 추가하지 않고 실제 줄 번호와 원인을 표시한다. 빈 줄과 UTF-8 BOM, CRLF 줄바꿈을 지원한다.

각 줄은 `state`, `question`, `target`을 가진 JSON 객체다. `state`는 문자열 또는 JSON 값이며, `question`은 그 예제의 질문과 선택지를 담는다. `target`은 선택지 순서에 맞춘 음수 없는 확률 배열이고 합은 1이어야 한다. `score`는 낮은 단계부터, `noul`은 `[false, true]` 순서다. 예를 들어 `[0, 1]`은 두 번째 답을 정답으로 지정하고, `[0.25, 0.75]`는 확률 분포를 지정한다.

[training.jsonl](./public/training.jsonl)을 참고하거나 화면의 **형식 예제**로 다운로드할 수 있다. 가져온 예제는 현재 입력 편집기와 독립적이다. 학습 전후 비교는 편집기에 입력한 분류 지시문과 문장으로 실행한다.

## BANKING77 실험 데이터

화면의 **한글 학습 90개**를 다운로드해 가져오면 카드 분실·도난, 송금 실패, 개인정보 변경 문의를 종류별 30개씩 한글로 학습할 수 있다. 문장·질문·선택지를 번역했으며 영문 원본도 데이터 폴더에 보관한다. **정확도 평가**의 **평가용 30개 불러오기**로 별도 평가 목록을 준비한다. [데이터 설명과 출처](./public/datasets/banking77/README.md)에 질문·선택지 설정과 추출 기준이 있다.

핵심 단어 없이 분류하는 추가 실험에는 **문맥 학습 60개**를 사용할 수 있다. [문맥 예제 설명](./public/datasets/context/README.md)에 구성과 사용법이 있다.

별도로 작성한 **새 평가 30개**는 세 분류를 각 10개씩 포함한 한국어 합성 문장이다. 기존 학습·평가·문맥 예제와 중복이 없으며 학습 목록에 넣지 않는다. [평가 데이터 설명](./public/datasets/generalization/README.md)에 작성 기준과 실행 전 확정한 파일 해시를 기록했다. 정답 예제 영역의 **학습 방법**에서 직접 예제 추가, JSONL 가져오기, 설정 적용과 평가 순서를 확인할 수 있다.

## 학습 전후 정확도 비교

1. 학습 예제를 가져오고 모델을 불러온다.
2. 기존 세트는 **평가용 30개 불러오기**, 추가 세트는 **새 평가 30개 불러오기**를 누른다. 임의의 파일은 **평가 JSONL 가져오기**로 선택한다. 평가 목록은 교체되며 학습 목록에 추가되지 않는다.
3. **학습하고 결과 비교**를 누른다. 현재 가중치로 평가 → 학습 예제만 학습 → 같은 평가 예제로 재평가 순서로 진행한다.

**정확도 평가**에 전후 정확도, 맞힌 수와 전체 수, 변화(%p)를 표시한다. **문장별 결과**를 펼치면 정답과 학습 전후 예측을 확인할 수 있다. 정확도는 가장 높은 확률의 선택지가 정답인 비율이다. `score`도 가장 높은 확률의 단계로 평가하며 연속 점수 오차를 측정하지 않는다. 평가 정답은 one-hot 배열이어야 하며 soft label은 거부한다.

전후 **평균 손실**은 같은 평가 예제의 정답 확률로 계산한 교차 엔트로피다. 낮을수록 정답에 더 높은 확률을 준다. 정확도가 같아도 손실은 바뀔 수 있다. 그래프의 **단계별 손실**은 각 예제를 갱신하기 직전 값으로, 첫 예제와 마지막 예제의 차이가 전체 학습 효과를 뜻하지는 않는다.

학습 전 정확도는 해당 학습 실행 직전의 가중치를 기준으로 한다. 반복 실행하면 이어서 학습한다. 앞선 학습에서 사용한 다른 예제나 이전 세션까지 추적하지는 않는다. 현재 학습 목록과 평가 목록에 공백·대소문자를 정규화한 같은 문장이 있으면 학습을 시작하지 않는다. 비슷한 의미의 다른 문장은 자동으로 검출하지 않는다.

평가 중에도 중지할 수 있으며 미완료 정확도는 표시하지 않는다. 완료된 학습 단계의 가중치는 남는다. 평가 파일 교체·비우기, 가중치 복원·연결 해제 시 이전 정확도 결과를 지운다. 평가 목록을 비워두면 기존처럼 현재 입력의 추론 전후만 비교한다.

## 가중치 보관

체크포인트는 JSON 파일로 다운로드하거나 다시 불러올 수 있다. 원본 모델이 같은 체크포인트만 적용할 수 있다. 초기 가중치 복원은 현재 세션에서 처음 불러온 가중치로 돌아간다. 연결 해제는 학습 가중치를 지우고 예제는 남긴다. 페이지를 새로고침하면 가중치와 예제가 모두 지워지므로 필요한 가중치는 먼저 다운로드한다.

기본 다국어 FP32 모델은 약 1.3 GB다. 학습 대상은 scorer이며, 언어 인코더와 앞쪽 Transformer는 고정한다. 확률은 별도 보정 전 값이다. 기본 예제는 기능 시연용이며 학습 후 일반적인 정확도를 증명하지 않는다.

## Production build

```sh
pnpm exec vite build --config packages/laya-wasm/demo/vite.config.ts
LAYA_MULTILINGUAL_MODEL_DIR=/tmp/laya-multilingual-browser \
LAYA_MODEL_DIR=/tmp/laya-browser pnpm exec vite preview \
  --config packages/laya-wasm/demo/vite.config.ts
```

빌드된 데모는 `demo/dist/`에 생성된다. 정적 호스팅에서는 준비 모델 폴더를 별도로 제공해야 한다.

## 검증

```sh
pnpm exec tsc -p packages/laya-wasm/demo/tsconfig.json
node packages/laya-wasm/demo/tests/model-files.mjs
LAYA_MULTILINGUAL_MODEL_DIR=/tmp/laya-multilingual-browser \
  node packages/laya-wasm/demo/tests/browser.mjs --production
LAYA_MULTILINGUAL_MODEL_DIR=/tmp/laya-multilingual-browser \
  LAYA_EVALUATION_REPORT=/tmp/laya-multilingual-evaluation.json \
  node packages/laya-wasm/demo/tests/evaluation.mjs
LAYA_MODEL_DIR=/tmp/laya-browser LAYA_EVALUATION_MODEL_URL=/models/laya/ \
  LAYA_EVALUATION_REPORT=/tmp/laya-english-evaluation.json \
  node packages/laya-wasm/demo/tests/evaluation.mjs
```

브라우저 테스트는 JSONL 일괄 가져오기와 오류 파일의 부분 추가 방지, UI에서 실제 모델 추론·학습, 체크포인트 파일 다운로드·복원, 학습 중지, 질문 유형 전환, 잘못된 파일 거부와 375px 화면의 가로 넘침을 확인한다.

같은 한글 평가 30개에서 영문 모델은 23/30(76.7%), 다국어 모델은 27/30(90.0%)이었다. 학습률 0.001로 학습 90개를 1회 반복한 뒤에도 각 모델의 정답 수는 같았다. [모델 비교 기록](./tests/evaluation.md)에 조건과 남은 오답을 기록했다.

다국어 모델을 초기 가중치에서 각각 3회·5회 학습하는 UI 실험에서도 27/30(90.0%)으로 같았다. 학습률을 0.01로 올린 3회·5회 조건도 모두 27/30이었다. 비교할 때는 **초기 가중치 복원**으로 누적 0단계를 확인한 뒤 설정을 바꾼다. 복원하지 않고 다시 학습하면 앞선 학습에 이어서 갱신한다.

추가 UI 실험에서 다국어 모델의 한국어 90개를 **학습률 0.1·100회**로 학습하자 27/30 → 30/30, 평가 평균 손실 0.2160 → 0.0647로 개선됐다. **한국어 90개 실험 설정** 버튼으로 이 값을 적용할 수 있다. 이 데이터용 실험값이며 다른 데이터의 기본 권장값은 아니다. 영문 모델에 같은 행의 영어 원문 90개를 0.01·5회 학습한 비교는 30/30 → 30/30, 평균 손실 0.1763 → 0.0060이었다. [원인 진단과 실험 기록](./tests/evaluation.md#학습-정체-원인-확인과-개선)에 학습이 실제로 진행됐는지 확인한 근거와 평가 한계를 정리했다.

`model-files.mjs`는 개발 서버와 프리뷰가 잘못 인코딩된 모델 경로, 없는 파일과 상위 폴더 접근을 각각 400·404·403으로 처리하고 이후에도 정상 요청을 받는지 확인한다.
