# 문맥 분류 학습 예제

[train.jsonl](./train.jsonl)은 이 데모를 위해 AI가 작성한 한국어 합성 예제 60개다. BANKING77 원문이나 번역에서 가져온 문장이 아니다.

| 선택지 순서 | 정답           | 예제 수 |
| ----------- | -------------- | ------- |
| 0           | 카드 분실·도난 | 20      |
| 1           | 송금 실패      | 20      |
| 2           | 개인정보 변경  | 20      |

분류할 문장인 `state`에는 `카드`, `송금`, `이체`를 쓰지 않았다. 질문과 정답 선택지에는 기존 학습 데이터와 동일한 이름을 사용한다. 결제 수단의 분실, 돈 보내기 실패, 이름·주소·연락처 수정 등의 상황으로 요청을 구분하도록 구성했다. 다른 종류의 상황을 언급하면서 실제 요청은 하나로 명확히 하는 예제도 포함한다.

데모의 **문맥 학습 60개**를 다운로드해 **JSONL 가져오기**로 가져온다. 기존 BANKING77 90개가 있으면 목록 뒤에 추가되어 총 150개가 된다. 정답 순서와 분류 지시문은 기존 한글판과 같다.

이 파일은 학습용이다. 학습한 문장을 다시 맞히는 것만으로 문맥 이해 성능을 판단하지 않는다. 별도로 작성한 문장이나 학습에 넣지 않은 평가 문장으로 비교한다. 기존 BANKING77 학습·평가 파일과 완전히 동일한 문장이 없음을 확인했으며, 표현이나 상황이 비슷한 문장은 있을 수 있다.
