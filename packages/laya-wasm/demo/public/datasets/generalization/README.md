# 새 한국어 평가 30개

2026-10-15에 이 데모의 추가 평가용으로 AI가 새로 작성한 합성 문장이다. BANKING77에서 발췌하거나 번역한 문장이 아니다. 카드 분실·도난, 송금 실패, 개인정보 변경을 각 10개씩 포함한다. 직접적인 문의와 핵심 단어를 생략한 문맥형 문의를 섞었다. 모든 문장은 하나의 요청만 담도록 검토했다.

[evaluation.jsonl](./evaluation.jsonl)은 **평가 전용**이다. 기존 BANKING77 학습 90개·평가 30개와 문맥 학습 60개에 대해 공백·대소문자 정규화 후 중복이 없음을 확인했다. 질문과 선택지 순서는 기존 한국어 학습 90개와 같다. 유형을 0, 1, 2 순서로 교대로 배치했다.

문장과 정답을 모델 실행 전에 확정했다. 초기 가중치에서 기존 학습 90개만 학습하며, 이 파일의 문장이나 정답은 가중치 갱신에 사용하지 않는다. 학습률 0.1·100회는 기존 평가 결과로 정한 설정을 그대로 사용하고, 새 평가 결과에 맞춰 다시 조정하지 않는다.

- 확정한 평가 파일 SHA-256: `4b3e7702efe7ad7358f2f09736598357bee8461116ad7fdb6bf944c64de30487`
- 사용: 정확도 평가의 **새 평가 30개 불러오기**, 또는 평가 JSONL 가져오기로 이 파일을 선택한다.
- 출처: 이 작업에서 작성한 합성 데이터. 실제 고객 문의의 무작위 표본이 아니므로 결과를 전체 서비스 정확도로 해석하지 않는다.
