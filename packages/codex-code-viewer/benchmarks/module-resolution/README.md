# 프로젝트 별칭과 선언 연결 검증

기존 단일 TypeScript 분석기의 모듈 해석을 수정했다. 프로젝트를 나눠 분석하는 실험은 적용하지 않았다.

- 각 파일의 가장 가까운 `tsconfig`와 상속 설정으로 import를 해석한다. 서로 다른 프로젝트의 같은 별칭을 구분한다.
- 워크스페이스의 단일 원본 선언 맵으로 `.d.ts`와 원본 모듈을 연결한다. 맵이 없는 워크스페이스 패키지는 `package.json`의 `source`·`types`와 대응하는 하위 경로를 사용한다.
- 검색 범위와 후보 인덱스도 같은 해석을 사용한다. 이전 방식으로 저장한 후보 인덱스는 다시 만든다.
- 루트 파일 추가와 해석 입력 변경 시 이전 모듈 해석을 무효화한다. 검색 워커가 실제로 읽은 선언·맵·패키지 정보의 메타데이터를 전달해, 탐색 트리에 없는 `dist` 안의 변경도 재조회에 반영한다.

## 결과

2026-10-13, Node 24.15.0 / TypeScript 런타임 6.0.3. 수정 직전 코드와 최종 코드를 각각 워커와 함께 번들링했다. 동일한 파일 집합에서 별도 프로세스·빈 `CODEX_HOME`으로 시작했고, 3회씩 실행 순서를 번갈아 비교했다. OS 파일 캐시는 비우지 않았다.

`workspace.read()` 이후 `scanNavigation()` 호출부터 측정했다. 첫 결과는 비어 있지 않은 실제 결과 배치를 받은 시점이고, 전체 완료는 스트림 종료 시점이다. 재조회는 같은 워크스페이스·프로세스에서 완료한 요청을 다시 실행했다. 브라우저 화면 그리기 시간과 프로세스 재시작 속도는 이 표에 포함하지 않았다.

수정 전 → 후, 3회 중앙값:

| 조회                                | 최초 첫 결과    | 최초 전체 완료    | 재조회 첫 결과 / 완료       | 결과 수  |
| ----------------------------------- | --------------- | ----------------- | --------------------------- | -------- |
| 대규모 프로젝트 별칭                | 323 → 343ms     | 643 → 603ms       | 8.41/8.43 → 10.80/10.82ms   | 11 → 14  |
| 대규모 선언 맵                      | 320 → 342ms     | 641 → 606ms       | 8.33/8.35 → 8.93/8.96ms     | 14 → 17  |
| 실제 모노레포 `fileRevision` 사용처 | 1.477 → 1.410초 | 10.834 → 12.704초 | 34.93/34.94 → 52.60/52.62ms | 15 → 15  |
| 실제 모노레포 `getWindow` 사용처    | 1.367 → 1.355초 | 11.623 → 12.828초 | 35.29/35.30 → 41.01/41.05ms | 22 → 102 |
| 앱에서 `getWindow` 정의 조회        | 707 → 709ms     | 747 → 751ms       | 28.24/28.26 → 27.94/27.95ms | 1 → 1    |

첫 결과 시간은 비슷했다. 실제 모노레포 전체 완료 시간은 1.2~1.9초 늘었다. 이번 변경을 속도 개선으로 평가하지 않는다. 3회 측정만으로 작은 차이의 통계적 유의성을 판단할 수는 없다. 수정 전 사용처 조회는 누락이 있어 결과 수가 다른 비교도 있다.

## 누락·오탐 검증

- 동명 심볼 2천 개를 넣은 기존 실험 fixture에서 별칭 **14/14**, 선언 맵 **17/17** 위치가 수작업 기대 집합과 정확히 일치했다. 각 3개 프로세스의 최초·재조회 결과가 동일했고, 추가 동명 심볼은 결과에 포함되지 않았다.
- 실제 모노레포 `getWindow`의 기존 22개 위치를 전부 유지했다. 추가 결과에는 `ServiceWorker.tsx`의 import와 49·93행 호출이 포함된다. 총 102개 중 앱에 65개, 패키지에 37개가 있다. 모든 102개의 독립적인 정답 집합을 따로 구축한 것은 아니다.
- 정의 조회는 `packages/utils/dist/browser/dom/get-window/index.d.ts`에서 `packages/utils/src/browser/dom/get-window/index.ts:1:14`로 바뀌었다.
- 통합 테스트는 같은 별칭의 프로젝트별 구분, 상속 설정, 재내보내기, 선언 맵, 맵 없는 패키지·하위 경로·심볼릭 링크, import/require 조건, 취소 복구, 파일 추가, 재조회, 재시작, 맵 대상 변경을 검증한다.
- 최종 전체 통합 테스트 **367/367**, 관련 Wallaby 단위 테스트 **22/22**, Node 환경의 워커 단위 테스트 **4/4** 통과. 타입 검사·oxlint·`pnpm format`·배포 빌드 통과.

여러 원본을 합친 선언 맵에서 개별 원본 위치를 추적하는 기능은 이번 수정에 포함하지 않았다. 원본이 없거나 연결 근거가 없으면 기존 선언으로 남긴다. 워크스페이스 밖 원본이나 설치된 외부 패키지를 임의로 소스에 연결하지 않는다.
