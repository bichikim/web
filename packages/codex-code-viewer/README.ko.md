# Code Viewer 사용 설명서

[English user guide](./README.md)

Code Viewer는 Codex 대화 옆에서 코드·문서·미디어를 여는 플러그인입니다. 관련 코드를 찾아가고, 텍스트 파일을 편집하고, 선택한 코드나 변경 내용을 다음 채팅의 참고 자료로 추가할 수 있습니다.

파일별 기능은 [지원 파일 형식](#지원-파일-형식)에서 확인하세요.

## 1. 설치하고 시작하기

Node.js 24 이상, npm, Codex 데스크톱 앱과 `plugin` 하위 명령을 지원하는 Codex CLI가 필요합니다. CLI가 없거나 업데이트가 필요하면 먼저 실행하세요.

```sh
npm install -g @openai/codex
```

Code Viewer를 설치합니다.

```sh
npx @winter-love/codex-code-viewer@latest install
```

Codex 앱을 완전히 종료하고 다시 여세요. 프로젝트 대화 오른쪽 패널의 새 탭 메뉴에서 **Code Viewer**를 선택합니다. 기본 파일 뷰어의 **열기** 메뉴는 외부 앱을 실행하는 메뉴입니다.

대화의 작업 폴더를 확인할 수 있으면 자동으로 연결합니다. 연결되지 않으면 `/Users/사용자명/projects/my-project/src/main.tsx`처럼 파일의 절대 경로를 입력하고 Enter를 누르세요.

업데이트할 때도 같은 설치 명령을 실행한 뒤 Codex를 다시 엽니다. 설치 상태는 다음 명령으로 확인합니다.

```sh
codex plugin list --json --marketplace winter-love-code-viewer-npm
```

다른 Codex 설정 폴더를 사용한다면 `CODEX_HOME`을 지정하세요. CLI가 PATH에 없으면 `CODEX_BINARY`에 실행 파일 경로를 지정합니다.

## 2. 파일 열고 찾기

- **경로로 열기:** 절대 경로나 연결된 작업 폴더 안의 상대 경로를 입력하고 Enter 또는 **파일 열기**를 누릅니다. 특정 위치로 이동하려면 `src/main.tsx:20:5`처럼 줄·열을 붙입니다.
- **이름으로 찾기:** `Cmd/Ctrl+P`를 누르고 파일명이나 경로 일부를 입력합니다. 위·아래 방향키와 Enter로 결과를 선택하거나 클릭합니다. Escape로 결과를 닫습니다.
- **폴더 둘러보기:** 검색 옆의 **파일 트리**를 누릅니다. 폴더를 클릭하면 펼치고 접으며, 파일을 클릭하면 엽니다. **파일 필터링**은 경로로 목록을 좁히고, **현재 파일 위치로 이동**은 필터를 비운 뒤 열린 파일까지 스크롤합니다.
- **이전 위치로 돌아가기:** 뒤로·앞으로 버튼이나 `Alt+←/→`를 사용합니다.

트리 경계선을 드래그하면 너비를 조절합니다. 경계선에 포커스를 두면 좌우 방향키로 너비를 바꾸고 Home/End로 최소·최대 너비를 선택합니다. 트리에서는 위·아래 방향키와 Home/End로 항목을 선택하고, 좌우 방향키로 폴더를 접고 펼칩니다. 우클릭이나 `Shift+F10`으로 항목 메뉴를 엽니다.

같은 탭에서 파일을 다시 열면 선택 범위·스크롤과 해당 형식의 미리보기·배율·페이지 설정을 복원합니다. 줄·열을 지정해 이동하면 그 위치를 우선합니다. 최근 64개 파일의 보기 상태를 작업 폴더별로 유지하며, 뷰어를 닫거나 다시 불러오면 초기화합니다.

## 3. 코드 읽고 이동하기

읽기 모드에서 import 경로를 클릭하면 모듈 파일을 열고, 심볼의 사용처를 클릭하면 정의로 이동합니다. 정의 이름을 클릭하면 사용처 목록을 엽니다. 결과는 파일별로 표시하며 항목을 선택해 이동합니다. 정의가 여러 개라면 목록에서 하나를 선택합니다.

정의·사용처 이동은 TypeScript·JavaScript·Python·Ruby·Rust에서 지원합니다. JSON·JSONC·JSON5는 파일 경로 값으로만 이동합니다. 그 외 형식은 구문 강조가 있어도 심볼 이동은 제공하지 않습니다. 언어별 준비 사항은 [코드 탐색 설정](#코드-탐색-설정)을 참고하세요.

편집 모드에서는 일반 클릭으로 커서를 옮깁니다. 코드 이동에는 `Cmd/Ctrl+클릭`이나 `F12`를 사용합니다. 결과 목록에서는 방향키와 Enter로 이동하고 Escape로 닫습니다.

`Cmd/Ctrl+F`로 현재 파일의 문자열을 검색합니다. 대소문자를 구분하지 않는 일반 문자열 검색이며, Enter/Shift+Enter로 다음·이전 결과로 이동하고 Escape로 닫습니다. Markdown·CSV·TSV는 원문으로 전환해 검색합니다. PDF는 문서 전용 검색을 사용합니다.

## 4. 텍스트 편집하고 저장하기

1. 편집 가능한 파일을 열고 문서 도구 줄의 **편집**을 누릅니다.
2. 내용을 수정합니다. `Cmd/Ctrl+Z`로 실행을 취소하고 `Cmd/Ctrl+Shift+Z`로 다시 실행합니다.
3. **저장** 또는 `Cmd/Ctrl+S`를 누릅니다. 자동 저장이나 자동 서식 변경은 하지 않습니다.

지원 형식 표의 텍스트 파일은 모두 편집할 수 있으며, Markdown·CSV·TSV는 원문을 편집합니다. PDF·Word·Excel·SVG와 그 외 미디어는 편집할 수 없습니다. HTML·Vue·Svelte·Astro는 실행 없이 원문만 편집합니다. 코드 탐색 분석기가 없어도 편집과 저장은 가능합니다.

다른 파일로 이동해도 초안은 남습니다. **편집**을 끄면 초안을 읽기 모드로 표시하며, 변경을 버리지는 않습니다. Markdown·CSV·TSV 미리보기에도 미저장 내용이 반영됩니다. 초안을 버리려면 편집 중 **⋯ → 변경 버리기**를 선택합니다.

TS·JS·JSON 탐색에는 미저장 초안을 사용합니다. Python·Ruby·Rust는 현재 파일의 초안만 분석하며 다른 파일의 초안을 함께 분석하지 않습니다.

다른 프로그램이 원본을 변경하면 저장을 거절하고 초안을 유지합니다. 변경 내용을 채팅에 첨부해 검토하거나, 변경을 버려 디스크의 원본을 다시 읽으세요. 외부에서 파일을 삭제했다면 **저장**으로 같은 경로에 다시 만들고, **변경 버리기**로 문서를 닫을 수 있습니다. 다른 프로그램이 먼저 파일을 복원했다면 저장 시 충돌을 안내합니다.

작업 폴더를 바꾸거나 Codex가 뷰어 종료를 요청하면 모두 저장·변경 버리기·계속 편집 중에서 선택합니다. 종료하거나 다시 불러오기 전에 초안을 저장하세요. 저장하지 않은 내용은 강제 종료 뒤에 복구할 수 없습니다.

## 5. 채팅에 파일과 변경 내용 추가하기

| 추가할 내용        | 사용 방법                                                                                                                               |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| 파일·폴더 전체     | 트리에서 우클릭한 뒤 **채팅창에 추가**를 선택합니다. 미디어나 뷰어에서 열 수 없는 파일도 경로를 첨부합니다.                             |
| 줄 범위            | 줄 번호를 클릭하거나 드래그합니다. Shift를 누른 채 다른 줄 번호를 클릭해도 됩니다. 이후 우클릭 메뉴에서 **채팅창에 추가**를 선택합니다. |
| 정확한 텍스트 범위 | 본문을 드래그한 뒤 우클릭 메뉴에서 **채팅창에 추가**를 선택합니다. 파일 경로와 시작·끝 줄 및 열이 함께 전달됩니다.                      |
| 미저장 변경분      | 편집 중 **⋯ → 변경 내용 채팅에 추가**를 선택해 현재 파일의 diff를 첨부합니다.                                                           |

편집기에서 선택한 범위는 미저장 내용을 포함합니다. 트리의 파일 첨부는 디스크 파일을 참조합니다. diff는 마지막으로 읽거나 저장한 내용과 비교하며, 첨부 시점의 변경분을 담습니다. 이후 내용을 수정했다면 다시 첨부하세요.

여러 파일의 범위를 차례로 추가할 수 있으며 다음 메시지의 참고 자료로 누적됩니다. 파일 저장과 메시지 전송은 별도로 합니다. Code Viewer가 메시지를 자동으로 보내지는 않습니다.

줄 번호 없이 복사하려면 코드 우클릭 메뉴의 **코드 복사**, 절대 경로를 복사하려면 트리의 **경로 복사**를 사용합니다. 선택 주소의 끝 위치는 범위에 포함하지 않습니다. `5:3-5:7`은 5번째 줄의 3~6번째 열입니다.

## 6. 파일과 폴더 관리하기

트리 도구 줄의 **새 파일**·**새 폴더**를 사용합니다. 폴더를 선택했다면 그 안에, 파일을 선택했다면 같은 상위 폴더에 만듭니다. 빈 작업 폴더에서는 루트에 만듭니다. 이름 입력창에서 생성 위치를 확인할 수 있으며 기존 항목은 덮어쓰지 않습니다.

파일·폴더 우클릭 메뉴에서 **이름 변경**·**복사**·**잘라내기**·**붙여넣기**·**삭제**를 선택합니다. 트리에 포커스가 있으면 `Cmd/Ctrl+C`·`X`·`V`와 Delete도 사용할 수 있습니다. 복사·잘라내기는 이 뷰어의 작업 폴더 안에서 사용하는 내부 클립보드입니다. 폴더에 붙여넣으면 그 안에, 파일에 붙여넣으면 같은 상위 폴더에 만듭니다. 빈 공간의 메뉴에서는 작업 폴더 루트에 붙여넣습니다. 복사 이름이 겹치면 복사본 이름을 만들고, 잘라내기·이름 변경은 오류를 안내합니다.

**삭제는 휴지통을 거치지 않는 영구 삭제입니다.** 확인창에서 대상을 확인하세요. 이름 변경·이동·삭제 전에 관련 초안을 저장하거나 버려야 합니다. 작업 폴더 자체, 심볼릭 링크와 `.git`·`.codex`·`.aws`·`.ssh`를 포함한 폴더는 보호합니다. 한 번에 최대 10,000개 항목을 처리할 수 있습니다. 작업 중 원본이 변경되면 중단되므로 내용을 확인한 뒤 다시 시도하세요.

## 지원 파일 형식

아래 표에서 파일 형식별 보기·탐색 기능과 편집 가능 여부를 확인하세요.

| 형식                  | 확장자·파일명                                                                  | 보기·탐색                                          | 편집 |
| --------------------- | ------------------------------------------------------------------------------ | -------------------------------------------------- | ---- |
| TypeScript·JavaScript | `.ts`, `.tsx`, `.mts`, `.cts`, `.js`, `.jsx`, `.mjs`, `.cjs`                   | 구문 강조·import·정의·사용처 이동                  | 가능 |
| Python                | `.py`, `.pyi`                                                                  | 구문 강조·import·정의·사용처 이동                  | 가능 |
| Ruby                  | `.rb`, `.rake`, `.gemspec`, `Gemfile`, `Rakefile`                              | 구문 강조·require 경로·정의·사용처 이동            | 가능 |
| Rust                  | `.rs`                                                                          | 구문 강조·모듈·정의·사용처 이동                    | 가능 |
| JSON                  | `.json`, `.jsonc`, `.json5`                                                    | 구문 강조·파일 경로 값 이동, 심볼 이동 없음        | 가능 |
| 설정 파일             | `.yaml`, `.yml`, `.toml`, `Cargo.lock`, `.ini`, `.conf`, `.cfg`, `.properties` | 구문 강조, 심볼 이동 없음                          | 가능 |
| 스타일                | `.css`, `.scss`, `.sass`, `.less`                                              | 구문 강조, 심볼 이동 없음                          | 가능 |
| 컴포넌트·마크업       | `.vue`, `.svelte`, `.astro`, `.html`, `.htm`, `.xml`                           | 원문 구문 강조, 심볼 이동·실행 없음                | 가능 |
| Markdown              | `.md`, `.markdown`, `.mdx`                                                     | 미리보기·원문, 표·체크리스트·상대 링크·이미지      | 원문 |
| CSV·TSV               | `.csv`, `.tsv`                                                                 | 표·원문, 정렬·필터·페이지 이동                     | 원문 |
| 일반 텍스트           | 확장자 없는 파일과 허용된 숨김 파일을 포함한 그 외 UTF-8 파일                  | 줄 번호·선택·검색, 언어별 구문 강조·심볼 이동 없음 | 가능 |
| PDF                   | `.pdf`                                                                         | 페이지·배율·텍스트 선택·문서 검색                  | 불가 |
| Word·Excel            | `.docx`, `.xlsx`                                                               | 문서 미리보기 / 시트 선택과 표 조작                | 불가 |
| SVG                   | `.svg`                                                                         | 이미지 미리보기 / XML 원문 강조·검색·범위 선택     | 불가 |
| 이미지                | `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.avif`, `.bmp`, `.ico`              | 확대·축소·이동                                     | 불가 |
| 영상                  | `.mp4`, `.m4v`, `.webm`, `.mov`, `.ogv`                                        | 재생 컨트롤                                        | 불가 |
| 음악                  | `.mp3`, `.wav`, `.m4a`, `.aac`, `.ogg`, `.oga`, `.opus`, `.flac`, `.weba`      | 재생 컨트롤                                        | 불가 |

`Cargo.lock`만 TOML로 강조하고 다른 `.lock` 파일은 일반 텍스트로 읽습니다. `.conf`·`.cfg`에는 INI 방식의 강조를 적용합니다. 확장자가 없는 파일은 트리나 경로 입력으로 여세요.

### 코드 탐색 설정

- **TypeScript·JavaScript:** 파일에 가장 가까운 tsconfig를 사용하며 `paths`, 상대 import와 barrel 내보내기를 해석합니다. 번들러 전용 별칭, 브라우저 public URL, 계산된 경로는 해석하지 못할 수 있습니다.
- **Python:** 별도 분석기 설치 없이 사용할 수 있습니다. 프로젝트 설정은 `pyrightconfig.json` 또는 `pyproject.toml`의 Pyright 설정을 따릅니다.
- **Ruby:** 프로젝트의 Ruby 환경에서 `gem install solargraph`로 Solargraph를 설치합니다. 실행 파일은 `SOLARGRAPH_BINARY`·`RUBY_BINARY`로 지정할 수 있습니다. 문자열 리터럴인 `require_relative`는 분석기 없이도 이동하며, 동적으로 만든 경로는 지원하지 않습니다.
- **Rust:** Rust·Cargo·rustup 설치 없이 사용할 수 있습니다. 첫 탐색에는 분석기를 내려받기 위한 GitHub Releases 연결이 필요하며, 다운로드 후에는 오프라인으로 사용할 수 있습니다. macOS·Linux·Windows의 x64·arm64를 지원하고 Linux에는 glibc가 필요합니다. 기존 분석기를 사용하려면 `RUST_ANALYZER_BINARY`에 실행 파일 경로를 지정하세요.

Rust는 독립 파일·모듈·로컬 Cargo 의존성을 탐색합니다. 표준 라이브러리·외부 패키지·추가 feature·생성 코드에 의존하는 정의는 찾지 못할 수 있습니다.

작업 폴더 밖에 있는 라이브러리의 정의는 열 수 없습니다. 분석기가 시작되지 않아도 읽기·구문 강조·편집·저장은 가능합니다. 자동완성·심볼 이름 변경 및 리팩터링·코드 실행은 제공하지 않습니다. 트리의 **이름 변경**은 파일·폴더 이름만 바꿉니다.

### 문서와 미디어 사용하기

- **Markdown·MDX:** **미리보기 / 원문**으로 전환합니다. 상대 문서 링크와 이미지는 작업 폴더 안에서만 열며 외부 이미지는 링크로 표시합니다. MDX 표현식·컴포넌트는 실행하지 않습니다. 줄·범위 첨부는 원문에서 사용합니다.
- **CSV·TSV:** **첫 행을 열 이름으로**를 켜거나 끄고, 열 이름으로 정렬하거나 **행 필터링**을 사용합니다. 처음 10,000행·100열을 한 번에 50행씩 미리 보며 정렬·필터도 이 범위에 적용합니다. 전체 내용과 줄·범위 첨부는 원문을 사용합니다. CSV 인용부호 오류가 있으면 원문으로 전환합니다.
- **Word:** DOCX의 제목·문단·목록·표·내장 이미지를 미리 봅니다. 원본 페이지 배치·글꼴·세부 서식은 재현하지 않으며 외부 이미지는 읽지 않습니다.
- **Excel:** 시트를 선택한 뒤 표 조작을 사용합니다. 숫자·날짜는 저장된 표시 형식, 수식은 재계산 없이 저장된 결과로 표시합니다. 시트별 미리보기 한도는 CSV와 같습니다. 셀 스타일·병합 배치·차트·이미지는 재현하지 않습니다. 이전 `.doc`·`.xls` 형식과 암호 입력은 지원하지 않습니다.
- **PDF:** 페이지 번호·배율(25–400%)을 입력하거나 **화면에 맞춤**을 사용합니다. 텍스트를 드래그해 선택·복사합니다. `Cmd/Ctrl+F`로 문서를 검색하고 Enter/Shift+Enter로 결과를 이동합니다. 검색 한도는 2,048페이지·4,194,304자·10,000개 결과입니다. 스캔 PDF는 텍스트 레이어가 있어야 검색할 수 있으며 OCR·암호 입력은 지원하지 않습니다.
- **이미지·SVG:** 배율 버튼·입력(1–1600%)·핀치·`Ctrl/Cmd+휠`로 확대·축소하고 드래그·방향키로 이동합니다. 이미지에 포커스가 있으면 `+`·`-`로 배율 조절, `0`으로 100%, Home으로 화면 맞춤을 사용합니다. SVG는 XML 원문도 볼 수 있지만 512 KiB를 넘으면 미리보기만 제공합니다.
- **영상·음악:** 재생 컨트롤을 사용합니다. 재생 가능 여부는 내장 브라우저의 코덱 지원에 따라 달라집니다. 음악은 재생 버튼을 눌러 시작하고 파일을 떠나면 멈춥니다.

## 제한과 문제 해결

| 상황                         | 확인할 내용                                                                                 |
| ---------------------------- | ------------------------------------------------------------------------------------------- |
| 작업 폴더 트리가 보이지 않음 | 파일의 절대 경로를 입력해 작업 폴더를 연결하세요.                                           |
| 파일이 없거나 열리지 않음    | 작업 폴더·경로 권한·인코딩·크기를 확인하세요. 보호 경로와 생성물·의존성 폴더는 제외합니다.  |
| 심볼을 눌러도 이동하지 않음  | 위의 지원 형식과 분석기 준비 사항을 확인하세요. 구문 강조만으로 이동을 지원하지는 않습니다. |
| 저장 충돌 안내               | 초안을 유지하거나 채팅에 첨부한 뒤, 준비되면 변경을 버려 디스크 원본을 다시 읽으세요.       |
| 재시작 뒤 변경 내용이 사라짐 | 초안은 종료 뒤 복구할 수 없습니다. 종료 전에 저장하세요.                                    |

텍스트는 NUL 바이트가 없는 UTF-8 파일로, 파일당 512 KiB까지 읽습니다. 문서·미디어는 128 MiB까지 지원합니다. 작업 폴더 밖과 `.git`·`.codex`·`.aws`·`.ssh`는 열지 않습니다. 숨김 파일은 `.dockerignore`, `.gitignore`, `.gitattributes`, `.gitmodules`, `.editorconfig`, `.prettierignore`, `.eslintignore`, `.npmignore`, `.browserslistrc`만 열 수 있습니다. `.env`는 열 수 없습니다. 검색 결과는 최대 100개까지 표시합니다. 검색과 트리에서 생성물·의존성 폴더는 제외합니다.

다른 프로그램에서 파일을 수정하면 뷰어 내용도 갱신됩니다. 미저장 초안은 유지합니다. 변경이 보이지 않으면 수동으로 새로고침하세요. 테마·글꼴은 Codex 설정을 따릅니다.
