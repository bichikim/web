# Codex 네이티브 파일 경로 동기화

Code Viewer의 파일 트리·검색·정의 이동·앞뒤 탐색에 맞춰 같은 Codex 탭의 경로, 제목과 외부 앱에서 열기 대상을 갱신하는 로컬 패치입니다.

공식 파일 확장 API에는 현재 탭의 파일 경로를 변경하는 메서드가 없습니다. 이 패치는 `winter-love/file-viewer/location` 기능을 제공하는 앱에서만 활성화됩니다. 패치가 없는 앱은 기존 동작을 유지합니다.

## 지원 범위

- 현재 확인한 macOS Codex 빌드 `26.930.61225`, `/Applications/ChatGPT.app`만 대상으로 준비했습니다.
- 현재 탭에 연결된 `code.file` 뷰어와 동일한 로컬 작업 폴더 안의 파일만 허용합니다.
- 원래 리소스 연결, 탭 ID와 뷰어 인스턴스를 유지합니다. 파일을 바꿀 때 탐색 기록과 선택이 초기화되지 않도록 초기 리소스 경로를 별도로 보존합니다.
- 버전, ASAR 헤더와 세 원본 JavaScript 파일의 SHA-256이 다르면 패치 생성을 중단합니다. 앱 업데이트 후에는 새 버전에 맞춘 검증이 필요합니다.

## 준비 명령

이 패키지 디렉터리에서 실행합니다. 설치 앱을 변경하지 않고 임시 디렉터리에 검토할 번들을 생성합니다.

```bash
node --import tsx build/native/stage.ts \
  /Applications/ChatGPT.app/Contents/Resources/app.asar \
  /private/tmp/codex-native-location-patch
```

`manifest.json`에 원본과 새 ASAR 헤더 해시가 기록됩니다. 나머지 원본 데이터는 그대로 복사하며, 수정한 세 엔트리의 파일 해시와 블록 해시를 다시 계산합니다. `Info.plist`의 `ElectronAsarIntegrity`도 새 헤더 해시와 일치해야 합니다.

## 설치와 복원

설치 전 원본 `.app` 전체를 복사해 서명까지 보존해야 합니다. 수정한 앱은 로컬 재서명이 필요하므로 OpenAI의 원래 서명과 달라집니다. 인증·키체인·알림 연동에 영향이 있을 수 있습니다. 실행 중인 앱에 곧바로 덮어쓰지 않고, 검증한 사본으로 교체한 뒤 재시작합니다.

복원할 때 앱을 종료하고 보존한 원본 `.app`를 다시 설치합니다. 사용자 설정과 채팅 데이터는 복원 작업의 변경 대상이 아닙니다.

검증된 준비 상태와 실제 설치·네이티브 화면 검증은 별개입니다. 최종 확인은 파일 트리에서 다른 파일을 열었을 때 같은 탭의 상단 경로·제목·열기 대상이 함께 바뀌고, 앞뒤 탐색이 유지되는지 확인해야 합니다.
