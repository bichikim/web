# Wallpaper

Pomo와 Wallpaper 앱이 공유하는 배경 모델·앨범 재생·전환 선택·미디어 저장소와 모니터별 설정이다. 네이티브 창은 `desktop-surface`, Puppet 렌더링은 `puppet`가 담당한다.

저장소 생성 시 데이터베이스 이름을 호출자가 지정한다. Pomo는 기존 이름을 유지하고 영상 캐시 콜백을 연결한다. 새 앱은 별도 이름을 사용한다. 호출자는 자신이 연 저장소의 구독을 해제하고 `close()`를 호출한다.

실행 제어는 연결된 모니터와 저장된 설정을 받아 주입된 창 어댑터에 적용한다. 앨범·Puppet은 로컬 렌더러를 사용하고 웹사이트 전환은 어댑터가 담당한다. 다음 동기화와 종료는 모든 모니터의 이전 작업이 완료된 뒤 실행한다. 앨범 재생 훅은 파일 로드·DOM 이벤트를 호출자가 연결하며 재생 순서·사진 시간·영상 종료 정책을 공유한다.

`frame-renderer`는 사진·영상 리소스, 여백 배경과 화면 전환을 소유한다. 호출자는 초기화한 렌더러를 종료할 때 `destroy()`하고, 콘텐츠 변경 중에는 `cancelPending()`으로 이전 로드·전환을 취소한다. 영상 배경 샘플 캐시는 선택적인 콜백으로 주입하며 Pomo의 저장소는 앱에 남긴다. 전환 셰이더의 MIT 고지는 렌더러 옆에 보관하고 사용하는 앱의 배포물에도 포함한다.

입력 상태 계산은 시간이나 네이티브 입력을 직접 읽지 않는다. 호출자가 단조 증가하는 타임스탬프와 입력·시간 경과 이벤트를 전달한다. 길게 누르기가 완료되어도 누름이 해제될 때까지 `releasing` 상태를 유지하므로 활성화 클릭을 웹사이트에 전달하지 않는다. 네이티브 입력 수집·카운트다운 표시는 앱의 후속 연결 작업이다.

전체 요구사항과 남은 단계는 [앱 계획](../../apps/wallpaper/README.md)에 기록한다.
