# ComfyUI

Use the ComfyUI MCP for supported operations; use the shell only for unsupported post-processing such as `ffmpeg` frame extraction.

Before local generation or model routing, read [references/local-setup.md](references/local-setup.md). Prefer compatible installed models and project workflows.

State why local execution is unsuitable before changing models or generation semantics, and obtain approval before paid generation.

For Pomo review work, preserve supplied endpoints, framing, identity, and palette; retain source video and native-rate lossless PNG frames without modifying runtime assets.
